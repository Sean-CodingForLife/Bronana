# 外部游戏机制档案（20 款）

> **这份文件回答什么**：别的游戏**怎么玩** —— 核心循环、玩家每分钟手上在做什么、
> 一局怎么分段、局内与局外各自长什么、失败要付什么代价、紧张从哪来、最核心的那个取舍是什么、
> 以及它独有什么、被夸什么、被骂什么。
>
> **它不回答什么**：不判定本作"好不好"，也不给"行业标准"。判定在
> [`../README.md`](../README.md) 与 [`skill-audit.md`](skill-audit.md)，
> **数值**在 [`external-benchmarks.md`](external-benchmarks.md) 与
> [`scaling-benchmarks.md`](scaling-benchmarks.md)。

⚠ **两条硬限制、先看清楚**：
① 本文覆盖 **20 款**（另有 1 款 RimWorld 只作旁证引用，**没有独立小节**）；
② 其中 **13 款是一级来源**（官方 wiki / 官方文档），**7 款是二级来源**（攻略站 / 分析文）——
**Loop Hero 与 Two Point Hospital 属于后者，而这两款恰好是本作营地的两位直接老师**。
抓取环境的限制（`fandom.com` 整机不可达、Steam 评测 API 不可达）逐条写在 **§二** 与 **§八**；
按"要找什么"反向查表见 **§七**。

## 二、来源强度标注（每款末尾都有一张出处表）

| 标注 | 含义 |
| --- | --- |
| `[实取]` | 实际抓到了该页面正文（wiki 走 MediaWiki API 取 wikitext 原文） |
| `[摘要]` | 只在搜索结果摘要或正文被截断的开头里看到 |
| `未取得` | 没找到，或找到了但取不到（403 / 付费墙 / 无该页面） |

⚠ **`未取得` 与"没有这件事"是两回事**。写 `未取得（没找到）` 意思是"这份文件没有证据"，
不意思是"这款游戏没有这个机制"。任何在本文基础上做的设计决策，
若依赖某个 `未取得` 的字段，**要先去补证据**。

⚠⚠ **抓取环境的两个真实限制（写在这里，免得下次以为是"这款游戏查不到"）**：

1. **`*.fandom.com` 在本机不可达** —— DNS 把它解析到了错误 IP
   （实测 `hades.fandom.com` → 157.240.9.36、`recettear.fandom.com` → 108.160.167.156），
   请求一律 `fetch failed`；`wikipedia.org` 与 `fextralife.com` 同样不可达。
2. **Steam 评测 API（`api/appreviews`）不可达**，但 `api/appdetails` 与 `api/storesearch` 可用。
   ⇒ 所以本文的「被称赞 / 被批评」两类字段**普遍偏薄**：它们的天然来源正是评测与媒体。

因此：**凡以 `fandom.com` 为出处的条目，本环境下无法复核**。
已知受影响的款：**元气骑士**（正文另有可靠来源，见该节出处表的说明）、
以及**只靠 fandom 的 5 款**（Recettear · Loop Hero · Two Point Hospital · 潜水员戴夫 · 咩咩启示录 · 夜勤人）。
其中后 6 款的部分事实来自**日文/中文攻略站**，出处的强度**低于官方 wiki**，
表里逐条标了实际域名 —— **引用前先看域名**。

## 三、怎么读每一款

**通读顺序**：`§四 横向综合`（先看结论）→ `§三之二 入选依据`（为什么是这些游戏）→
`§五 逐游戏档案`（20 款 × 19 个字段）→ `§七 快速索引`（按"要找什么"反查）→
`§八 来源总清单`（哪条能不能复核）→ `§九 本作站在哪`（一张总对照表）。

每款固定 19 个字段 + 一张出处表，分四段：

| 段 | 字段 | 回答的问题 |
| --- | --- | --- |
| **它是什么** | `定位` `一句话` | 类型 / 视角 / 谁做的 / 什么平台；一句话说清它是什么 |
| **它怎么玩** | `核心循环` `单局形状` `每分钟在做什么` `一局怎么分段` `操作方式` | 循环怎么转；手上动作是什么；分段之间的节奏 |
| **它怎么长** | `局内成长` `物品设计` `局外成长` `难度机制` | 成长发生在哪、频率、取舍；装备/词条结构；难度是选的还是解锁的 |
| **它的压力与结论** | `敌人与 Boss` `失败代价` `紧张从哪来` `核心取舍` `独有机制` `被称赞` `被批评` `对 Bronana 的三条` | 张力与取舍；**这一节是全文的目的地** |

⚠ **"对 Bronana 的三条"是判据，不是感想。** 每条都写成"在 X 和 Y 之间选 / 把 Z 做成 W"
这种能直接动手或能直接否掉的形式，并注明它对应本作的哪个模块（战斗 / 经营 / 养成）。

# 五、横向综合：把这些游戏拆成三条轴

> 这一节**先读**：它把后面的 20 份档案**按本作的三条轴重新切一遍**，
> 每条轴写"共识 / 分歧 / 本作站在哪"。
> 本作的实际参数直接读源码与 [`../README.md`](../README.md)，**不在这里抄第二遍**。

## 4.1 战斗轴：动作 roguelite 的七条共识

**① 单局是"可预期的有限段数"，不是无上限。**
Brotato 20 波封顶、Gunboat 5 层、Isaac 打到结局层、VS 按 15/20/30 分钟关卡计时收尾。
**RoR2 是唯一无上限的那一款**，而它的难度系数是"时间 × 关卡"的显式函数 ——
也就是说：**不封闭单局的游戏，必须把时间本身做成难度条**。
→ 本作选了前一条（撑到第 20 波并清场 = 通关），所以本作**不需要**时间难度条。

**② 一局内部要分两级节奏：小节点 + 大节点。**
Brotato 是"波（20~60 秒）→ 商店"；Gungeon 是"房间 → Boss 房"；Hades 是"房间 → 区域 Boss"；
Isaac 是"房间 → 楼层"。**小节点给资源，大节点给身份变化**（Boss 道具 / 区域祝福 / 新层）。
→ 本作两级都有（波 → 商店；房间 → 每 5 房间的 Boss），但**大节点给的东西偏资源**，
这一条值得对照 Hades 的 Boon 与 Isaac 的 Boss 道具池再看一遍。

**③ "抉择点"几乎总是绑在结算之后，不绑在战斗中。**
Brotato 每波后 1 次商店、Isaac 每层 1 次 Boss 道具、Hades 每间房门口 1 次门选择、
StS 每场战斗后 1 次卡牌三选一。**没有一款让你在战斗中做构筑决策**（除了"现在按不按技能"）。
→ 本作把技能做成有能量的手动选择（`manual` 模式），这在这条共识之外 ——
**是本作自己的一条差异，代价与收益都要自己量**（`tools/_run.mjs` 的机器人目前不装技能）。

**④ 玩家侧成长普遍是"衰减收益 + 稀缺乘法器"，不是线性加算。**
Isaac 的伤害走平方根（第 1 个 +1 值 1.69、第 2 个只值 1.26）；
RoR2 的叠加分四型（线性 / 双曲 / 倒数 / 指数），用双曲封顶（Tougher Times 十层也只到 60%）；
Dead Cells 的 Stat 是 ×1.15 复利但**玩家 HP 二次且硬封顶**；
Balatro 干脆把它做成乘法（Chips × Mult）。
→ 本作的道具是**带负代价的结构化 cost**（`data_items.ts` 的 `COST_KINDS`），
走的是"每件都在换东西"这条路，与上面几家的"公式衰减"是**两条不同的路**。
两条路都成立，但**不能同时用**：叠了公式衰减又叠负代价，玩家会觉得双重惩罚。

**⑤ 难度分两套：一套是"开局前可选的乘数"，一套是"逐级解锁的阶梯"。**
Hades 的 Heat 是**手动档且后置解锁**（打赢冥王一次才开放）；RoR2 的 Drizzle/Rainstorm/Monsoon 是开局选；
Brotato 的 Danger 是**逐级解锁**；Dead Cells 的 BSC 是解锁后层层叠；
DRG 的 Hazard 1–5 是**开局自选且与奖励直接挂钩**；Gungeon 的诅咒是玩家**主动加码**。
→ 本作是"难度阶梯 10 级 + 打赢 N 解锁 N+1"，属**逐级解锁**那一类。
Brotato 给这条路的必备配套是：**每一档的修正要写出绝对值而不是累加**（D5 = +40%，不是 12%+26%+40%）。

**⑥ 精英的设计判据：离散、条件触发、倍率固定。**
Isaac 的 Champion 是 ×2~×6 固定倍率、Gungeon 的 Jammed 是固定倍率 + 诅咒驱动出现率、
Dead Cells 的精英是固定额外倍率。**唯一同步放大的 RoR2 因此挨过打** ——
补丁原话是玩家反馈精英血"感觉虚胖"，以至于某件道具（Old Guillotine）变成必需品，于是两次下调。
**它同时给定了一条反判据：若某一件道具成为"打精英的默认解"，那是精英倍率过高。**
→ 本作的精英是"逐只掷、上限 24%、×3.2 固定"（见 `scaling-benchmarks.md`），
倍率固定 ✔，但**"逐只掷"让它必然出现** —— 与"离散、条件触发"不完全同向。

**⑦ 失败要有产出，且产出要走"解锁"而不是"数值"。**
Gungeon 的 Hegemony Credits、Hades 的 Darkness、Dead Cells 的细胞、Isaac 的解锁与成就、
Soul Knight 的宝石、DRG 的 25% 保底、Balatro 的收集品 ——
**全部是"下一局能多点什么"，而不是"下一局伤害 +5%"**。
最极端的一条是 Hades：**死亡推进剧情**（本作 `story.ts` 已照这条做了）。
→ 本作的孢子与天赋点走的是同一条路（据点买的是**功能**，`stronghold.ts` 注释写明
"纯数值的永久强化会稀释每局从零开始"）—— **这是本作与共识一致的地方，可以放心**。

## 4.2 经营轴：真正有经营的几款，共识更硬

**① 经营必须有一条"进入战斗"的通道，否则它就是菜单。**
Cult of the Lamb（教团 → 远征更强）、Dave the Diver（寿司店 → 潜水装备）、
Moonlighter（定价收入 → 地牢装备）、Recettear（商店收入 → 还债与雇人）、
Stardew（农场 → 矿洞与工具）都是这样。**没有一款是"战斗归战斗、经营归经营"。**
→ 本作的三柱闭环（打 → 造 → 再打）与这条一致，且
`stronghold.ts` 把"据点 → 营地容量与折扣"写成了**必须有**的连接线（自检里没有就报错）。

**② 经营的压力几乎总是来自"一个不可协商的倒计时或额度"。**
Recettear 是**每周还债**、Dave the Diver 是**氧气与负重上限**、
Stardew 是**一天的时间与体力**、Two Point Hospital 是**排队与关卡目标**。
共同点：压力**不是敌人给的，是账本给的**，所以它逼玩家在"再赚一点"和"现在收手"之间选。
→ 本作局内营地花的是**本局材料**，而材料同时是商店的钱 ——
这条"投产线还是投自己"的取舍与戴夫的氧气/负重是同一种形状（增量上限）。

**③ 瓶颈本身是玩法，不是缺陷。**
Two Point Hospital 的排队、RimWorld 的设施位、Loop Hero 的**地形相邻**、
Dave the Diver 的负重上限 —— 玩家做的事就是**挪动瓶颈**。
→ 本作局内营地是"3 个设施位 + 5 种设施 + 按建造顺序相邻才生效"（`camp.ts`），
这正是 Loop Hero 的相邻组合与 Two Point 的瓶颈那两层的合成。

**④ 定价值得单独做一层，而且是"玩家自己猜"。**
Moonlighter 让玩家自己给货架定价、记录每件东西的畅销价（"学会猜价格"本身就是乐趣）；
Recettear 把讨价还价做成**顾客报价条**（压太狠会跑掉），并给出各客层的具体阈值。
→ 本作的价格是**表定的**（`market.ts` 的货架 / 刷新 / 回收），**没有"定价"这一层**。
但要注意：这两家的定价之所以成立，是因为它们各有"顾客"这个独立模拟层。
本作要不要引入，是**设计决策**，不是补一个滑块。

**⑤ 经营的产物最好是"功能"，不是数值。**
Darkest Dungeon 的 Guild **不直接发技能等级**，而是解锁更高技能等级并降费；
Loop Hero 的 Gymnasium 解锁特性、Crypt 解锁职业；DD 的 Districts 才是少数纯被动。
→ 本作据点照这条做了（`stronghold.ts` 注释里逐条写明出处）——
   而**唯一明显缺的是"会衰减、必须定期照顾"那一层**（咩咩启示录的食料 / 卫生 / 忠诚心）。

**⑥ 经营与战斗之间不要用"自动产出"连接。**
Dave the Diver 的寿司店要玩家自己排菜单、Moonlighter 要玩家自己摆货定价、
Recettear 要玩家自己讨价还价 —— **没有一款让经营自动给战斗发资源**。
→ 本作 `craft.ts` 的注释里写了同一条（经营产出**不是自动的**，玩家自己消费材料打造）。

## 4.3 养成轴：元进度的六条判据

**① 元进度的第一层永远是"开局条件"，不是"永久数值"。**
StS 的解锁给新卡与遗物进池、Dead Cells 的 Runes 是**能力门**（改变地图可达性而非数值）、
Soul Knight 的角色星级是**开局属性与技能**、Hades 的 Mirror 是开局能力、
DRG 的晋升解锁的是**新玩法**（Machine Events / Deep Dives / The Forge）。
→ 本作的天赋树产物"只是开局条件"（`talents.ts`）与这条一致。

**② 解锁要能被"说清条件"，并且条件可以跨局累计。**
Brotato 的 62 个角色里只有 5 个默认解锁，其余来自三类条件：
难度档（Win a run in Danger N）、跨局累计（Kill 300/2000/5000/10000/20000）、
单局行为（Finish a wave with 1 HP）；
StS 的 Ascension 是**每个角色独立推进**；Balatro 的 Stake 是**每个牌组独立推进**。
→ 本作有挑战表（`challenges.ts` 参照 Brotato 的 Progress 表），形状一致；
"**每角色独立解锁难度**"这一点本作也有（见 README 的难度阶梯一节）。

**③ 词条有两条互相冲突的主流做法，必须显式选一条。**
**独立槽位派**：Last Epoch（2 前缀 + 2 后缀，各占独立槽）、PoE、Diablo。
**并集权重派**：本作（家族只是语义分组 + 权重，`roll` 从并集按权重抽）。
本作的选择在 `docs/requirements.md` 的 R39 里**写明了理由**（"进攻向 / 防护向"而不是两个槽），
代价是"一件装备可以滚出两条前缀、零条后缀"。
→ 这不是"缺了一半"，是**一条有意的路线**。引用外部时**必须引 Last Epoch 那一段的反面**，
不能引成"行业标准是 2+2"。

**④ 词条的档位必须单调，而且"造"与"刷"要各有不可替代的产出。**
Last Epoch 的硬规矩是"低档的最高值 < 高档的最低值"，
且 **7 档里只有 1~5 档能造，T6/T7 只能靠掉落**。
本作在 R39 里为"单调"补了守卫（每档显示非零数字、档位单调、cap 跟着物品品级长），
但**"造"与"刷"的分工还没做**（`roll` 只在生成时调用）。
→ **这是本作可以引外部补齐的一处**，而且外部有完整做法。

**⑤ 改良已有装备需要一条"路径"，否则词条是一次性抽奖。**
Last Epoch 有 Crafting（4 种符文：重掷数值 / 换词条 / 锁数值 / 封印腾槽）并且每次改良吃
**Forging Potential**（用完就锁死）；Moonlighter 的装备靠"素材 + 钱"打造。
本作目前只有合成时的 `merge`（各取更好的一条）—— R39 已把这一点记为缺口。
→ **这是本作明确的下一步候选**。

**⑥ 难度的"加码"要能让玩家量化自己的选择。**
Gungeon 的 Curse 每一笔来源标了数值（偷店 +1、祈祷 +3.5）、
RoR2 的 Shrine of the Mountain 明说 +100% 敌人换 +100% 掉落、
Brotato 的 Curse 直接标出 +150% HP / +25% 伤害换更多材料、
DRG 的 Mutator 明码标价（Low Oxygen +20%）。
→ 本作的道具已经有"敌人型代价"（`data_items.ts` 的 `enemy` 折法），
**形状与这几家一致**；差的是**界面上有没有把它标成一个数**。

## 4.4 这些参考里"没有先例"的三件事（本作自己的路）

写清这三条，是为了防止下次拿"外部参考"去否掉本作**有意**的设计：

1. **三条平级玩法轴的闭环**。同类 roguelite 都是"一局 + 一个元层"两层；
   有经营的那几款是"两个模块"，**没有一款是三轴平级且各自独立成立**。
   所以"营地该不该碰战斗数值"这类问题，**外部没有答案**，只能按本作自己的判据
   （`camp.ts`：五个效果键一个都不碰战斗数值）。
2. **局内就有"制造"，且与商店共用同一笔材料**。Dave the Diver / Moonlighter 的制造在局外；
   Brotato / VS 根本没有制造。**"这一波投产线还是投自己"是本作独有的取舍。**
3. **技能是有能量的手动构筑，而不是"多一把武器"**。本作 `manual` 模式把构筑决策带进了战斗中，
   而共识③说同类游戏都把它放在结算后。**这是一条自觉的差异**，
   因此它的影响必须被单独量（当前 `tools/_run.mjs` 的机器人**不装技能**，
   所以所有实机读数都是"零技能"对局 —— 这一点记在 `docs/requirements.md` 的 R38 里）。

## A · 动作幸存者：本作战斗模块的原型

<a id="g-vs"></a>
### 1. 吸血鬼幸存者 / Vampire Survivors

**定位**
poncle 开发的"割草式"肉鸽：一局固定时长，**武器全自动开火，玩家只负责走位**；
局内靠升级三选一成型，局外用金币买永久属性 `[实取]`。

**一句话**
你只有走位一项操作，其余交给自动开火的武器与升级三选一。

**核心循环**
`击杀 → 捡经验 → 升级三选一 → 武器变强 → 杀更多` 的正循环，撑到关卡时限通关；
Boss 宝箱按"基础武器升满 + 特定被动"给进化，构成**局内的中期目标** `[实取]`。

**单局形状**
单局固定时限：Wiki 明载 `30:00, 20:00, or 15:00 depending on the stage`；
到时 `one Reaper will arrive every minute to slay the player and end their run`。
死亡或到时即结算，**金币保留** `[实取]`。

**每分钟在做什么**
选角色选关后进场：走位躲怪、捡经验与金币，升级弹窗**暂停**并做选择，
Boss 掉宝箱，10 分钟后宝箱可进化；计时器推着整局走 `[实取]`。

**一局怎么分段**
无楼层，单张开放地图；敌人按分钟换波次，关卡时限即终点，Endless 模式改为循环重刷 `[实取]`。

**操作方式**
方向键/摇杆移动，**武器自动攻击**；升级与宝箱界面暂停并做选择
（可选 Skip 保留经验、Reroll 换一批）`[实取]`。

**局内成长**
纯靠升级与宝箱：武器与被动**各上限 6 格**，选中已有物品即升一级；
被动不能用空格 —— Wiki：`cannot be offered new items if the already have 6 different passive items or weapons` `[实取]`。

**物品设计**
武器/被动按稀有度带权重抽取（Wiki：约 `P(item)=itemRarity/itemPoolWeight`）；
宝箱首奖固定给随机金币 60~500；**进化时 `the base weapon is typically removed and the evolved
weapon is added`，不占额外槽位** —— 这一点很关键：进化是"换掉"而不是"多一把" `[实取]`。

**局外成长**
金币是永久货币：买 PowerUp（跨角色永久属性）、解锁角色与商家服务。
**PowerUp 可整笔退还（Refund PowerUps）**，升满后还能单独关掉以测试配装 `[实取]`。
（27 个 PowerUp 与成本公式见 [`external-benchmarks.md`](external-benchmarks.md) 的 §7.1。）

**难度机制**
Curse 加成敌人的速度、血量、波次频率与数量；刷怪间隔按
`effectiveSpawnInterval = spawnInterval / totalCurse` 缩短；
模式层还有 Hyper（移速 +65%~75%、金币 +50%）与 Hurry（计时双速）`[实取]`。

**敌人与 Boss**
普通波次按分钟推进；**Boss 是进化宝箱的开关**（多数关卡 10 分钟后），
时限到后每分钟刷 The Reaper 强制终结本局；Wiki 记同屏敌上限 **500** `[实取]`。
（关卡修正与四种模式的完整乘数见 [`external-benchmarks.md`](external-benchmarks.md) 的 §6.3。）

**失败代价**
结束时结算金币，**永久进度与解锁全部保留**；Wiki：
`the player will earn 500 gold coins as an additional reward upon death`，每剩一个复活再 +100 `[实取]`。

**紧张从哪来**
屏幕被怪填满的压迫感与"到时 Reaper 必到"的倒计时；Curse 越高越危险，但击杀量与经验也越多 `[实取]`。

**核心取舍**
每次升级从 3~4 个选项里取一，Skip 拿经验还是 Reroll 换一批；
**被动选谁决定了哪把基础武器能进化**；要不要为了经验主动堆 Curse `[实取]`。

**独有机制**
**进化即乘法结构**：某基础武器升满 + 特定被动 = 质变新武器
（如 Whip + Hollow Heart = Bloody Tear），且武器与被动两种投入**各只占一格** `[实取]`。

**被称赞**
构建成型后屏幕被一次性清空的爽感；15~30 分钟一局的短周期；
凑齐"最后一块拼图"触发进化的瞬间 `[摘要]`（这一条来自本轮抓取的概括，非逐字引文）。

**被批评**
**未取得（没找到）** —— 抓到的 wiki 页正文只写机制与改动史，
没有玩家批评原文，故不转述媒体或评述 `[实取]`。

**对 Bronana 的三条**

1. **关卡计时器当作硬结束条件**，不靠无限刷怪拖时长。→ **战斗**：
   本作每波"撑满时间即过关"已是同一形状，可对照的是 VS 的
   **"到时后每分钟来一次 Reaper"**（到点不是立刻掐断，而是给出倒计时式的强制收束）。
2. **升级三选一要给"跳过 / 重抽"**（Skip 保留经验、Reroll 换一批）。→ **养成**：
   本作据点已有 `freeRerolls`，可补的是"跳过并留经验"这条出口。
3. **进化=满级基础 + 指定件，且换掉而不是多一把**。→ **养成 / 战斗**：
   本作已有"同名同档两把合成一把更高的"（`combine`），
   与 VS 的差异是**合成对象是同类而不是指定配对** —— 后者更"像谜题"、前者更"像积累"。
   两条都成立，但**不要同时要求玩家做两件事**（既凑配对又凑同名）。

**出处**

- `[实取]` <https://vampire.survivors.wiki/api.php?action=parse&page=Evolution&prop=wikitext&format=json&formatversion=2>
  —— 进化条件与武器 + 被动配对、槽位与"移除基础武器再加进化武器"的规则
- `[实取]` <https://vampire.survivors.wiki/api.php?action=parse&page=Level_up&prop=wikitext&format=json&formatversion=2>
  —— 升级三选一、经验曲线、Luck 影响第四选项、六格上限
- `[实取]` <https://vampire.survivors.wiki/api.php?action=parse&page=Stages&prop=wikitext&format=json&formatversion=2>
  —— 15/20/30 分钟时限、The Reaper、Hyper/Hurry/Inverse/Endless
- `[实取]` <https://vampire.survivors.wiki/api.php?action=parse&page=Curse&prop=wikitext&format=json&formatversion=2>
  —— Curse 加成项、刷怪间隔公式、同屏 500 上限
- `[实取]` <https://vampire.survivors.wiki/api.php?action=parse&page=PowerUps&prop=wikitext&format=json&formatversion=2>
  —— PowerUp 的整笔退还与单项开关（数值与成本公式在 `external-benchmarks.md` §7.1）


<a id="g-hades"></a>
### 2. 哈迪斯 / Hades

**定位**
Supergiant Games 2020 年发行的 rogue-like 地下城爬行游戏，Metacritic 93，
Steam 全手柄支持、单机。叙事密度高，房间程序生成 `[实取]`。

**一句话**
扮演冥王之子扎格列欧斯，一次次逃出冥界，**死亡即剧情推进**。

**核心循环**
战斗 → 三选一**门** → 拿神赐（Boon）→ 继续推进；
中途死亡回冥府，用持久资源强化后再出发 `[实取]`。

**单局形状**
一次逃脱跨四大区域：**塔尔塔罗斯、阿斯福德、爱丽舍、冥河神殿**，每区末尾有守护者 Boss，
最终面对冥王本人 `[实取]`。

**每分钟在做什么**
实时动作：攻击、特殊、冲刺、投掷；每清空一间，走廊尽头出现数道门，
**门上图标预告下一间给什么奖励** `[实取]`。这是本作"房间选择"最直接的外部样本。

**一局怎么分段**
局内只靠 **Boon / Pom / 代达罗斯之锤**堆积强度，**全部随死亡清零**；
局外成长走**镜与工头翻新** `[实取]`。

**操作方式**
手柄全支持、键鼠亦可；攻击 / 特殊 / 冲刺 / 投掷 / 召唤为主动作
（Steam 类别 `full controller support`）`[实取]`。

**局内成长**
Boon 可被强化；**Pom of Power 直接提升某个 Boon 等级**，
在 Erebus 完美通关后一次可升两级 `[实取]`。

**物品设计**
局内货币为**卡戎之硬币**，可在商人与卡戎之井消费；
奖励分**持久与临时两类**，持久者含黑暗、冥界钥匙、仙馔、泰坦之血、宝石、钻石与安布罗西亚 `[实取]`。

**局外成长**
**镜与夜**在扎格列欧斯卧室，由倪克斯在**首次逃脱尝试后**引入。
共 12 个红色能力 + 12 个绿色替代能力，全满需 **35,365 黑暗 + 65 把冥界钥匙** `[实取]`。
（成本拆解与首胜时的累计量见 [`external-benchmarks.md`](external-benchmarks.md) 的 §7.2。）

**难度机制**
**惩罚契约**是一组**开局选择的运行修正**，每项分档，总档位和叫 **Heat**；
需要**击败冥王一次后才开放**（也就是说难度旋钮**与进度解耦**但**后置解锁**）`[实取]`。

**敌人与 Boss**
守卫 Boss 会**记住你**；惩罚契约里有"极端手段"，
每级给一个冥界 Boss **添加新招式** `[实取]`。

**失败代价**
死亡即回到冥府：可花黑暗/钥匙点镜与夜、给角色送仙馔换纪念品、用宝石找工头翻新，
并**触发新的对话事件** `[实取]`。

**紧张从哪来**
单局可能随时终结，而**持久资源与剧情推进只在回冥府后结算**；
Heat 越高，奖励越值钱但容错越低 `[实取]`。

**核心取舍**
**同一 Heat 与同一武器重复通关只给黑暗、不再给赏金** ——
必须再加档位才能继续拿血、钻石与安布罗西亚 `[实取]`。
这条把"继续加难度"变成**拿奖励的前提**，是本作没有的一层。

**独有机制**
**把难度做成玩家自选的旋钮**：惩罚契约 14 项修正，每项按档计 Heat，
例如"苦工"每档 +20% 受伤、"持续后果"每档 −25% 回血 `[实取]`。

**被称赞**
镜与夜提供"永久变强"的确定感，让手残玩家也能体验战斗与剧情；
"极端手段"让 Boss 战随熟练度不断翻新 `[实取]`。

**被批评**
① **赏金与 Heat 绑定**，导致重复刷同一档位零收益、必须持续加难度；
② **镜与夜总计 35,365 黑暗**的消耗梯度**对新手偏长** `[实取]`。

**对 Bronana 的三条**

1. **门奖励先预告再选** —— 战斗轴给玩家**节奏控制权**。→ **战斗**：
   本作已有"自己选房间"（`chamber.ts` / `Game.doors()`），
   ⚠ **缺的是"门上预告下一间给什么"** —— 有了预告，选择才是决策；没有预告，只是抽奖。
2. **元进度货币与难度解耦**：经营轴养数值，难度另设旋钮。→ **养成 / 战斗**：
   本作是"难度阶梯 10 级 + 打赢 N 解锁 N+1"（逐级解锁），
   与 Hades 的 **手动档 + 后置解锁**是同类但**不叠加赏金**；
   可借鉴的是"**加难度本身给额外产出**"这一条（本作的难度只影响敌人数值）。
3. **同一把武器换 Aspect 即换招式**，养成轴做成多套 build。→ **养成**：
   本作 9 个角色各有专属技能集，与 Aspects 的目的一致（**同一入口多条 build 线**），
   可以对照的是 Hades 把"换招式"挂在**局外解锁 + 泰坦之血**上，而不是挂在角色上。

  —— 类型定位、手柄全支持、单机、镜与夜与永久变强、Boon 与剧情事件

### 3. 死亡细胞 / Dead Cells

**定位**
Motion Twin 2018 年发行的 2D 横版动作平台 roguelite，官方自我介绍为
`roguelite, metroidvania inspired, action-platformer`。
Steam 约 15.66 万条评测、Metacritic 89，含 8 个 DLC，支持手柄与创意工坊 `[实取]`。

**一句话**
**没有存档点**的横版肉鸽：一局死透即重开，
但**符文、图纸、锻造品质与难度层永久留在存档里**，让下一局能走到更远。

**核心循环**
程序生成关卡内探索清怪 → 掉细胞与金币、捡卷轴和装备 → 出关进 **Passage** 花细胞解锁图纸、
升锻造、换变异、补血 → 打 Boss → 死亡或通关，回起点重来 `[实取]`。

**单局形状**
一局约 **30~60 分钟**：从 Prisoners' Quarters 起穿 **6~8 个层级**到最终 Boss。
图内有 **2 分钟、8 分钟、26 分钟**的限时门与无伤门，
逼玩家在"多搜"与"快跑"之间长期取舍 `[实取]`。

**每分钟在做什么**
跑图、清怪、翻找卷轴与宝箱，同时管理血量、**诅咒状态**和剩余时间；
出关后的 Passage 是**唯一整理窗口** —— 花细胞、改变异、补血瓶、交图纸 `[实取]`。

**一局怎么分段**
层级制推进：**每层只能进一张图**（`only one biome of each level`），
图与图之间由固定顺序加上**符文门、钥匙门、BSC 门**决定分支；
每张图末尾出口通往下一层，靠 Passage 中转，Boss 关作节点 `[实取]`。

**操作方式**
键鼠或手柄（Steam 标 Full controller support）。双武器槽加盾/技能槽，
操作为跳、翻滚（官方称 `emergency panic roll`）、下砸；
符文再补藤蔓、传送、撞墙、贴墙与离体头部 `[实取]`。

**局内成长**
几乎全压在**三点数**上：每点让对应颜色武器 DPS ×1.15（`1.15^(n-1)`），血量按三色乘子连乘。
图越深装备等级越高，**最多同时挂 3 个变异** `[实取]`。

**物品设计**
武器/技能/盾/护身符各挂一到两色，按**较高那色**缩放；
品质 `+/++/S` 的掉率由 Blacksmith 的 Legendary Forge **用细胞永久提升**；
无色与传奇物品按**最高点数**缩放，商店可花钱刷新 `[实取]`。

**局外成长**
永久保留：**10 个符文**（含 2 个 Richter Mode 专属）、交给 Collector 花细胞解锁的图纸、
Health Flask I~IV 与 Gold Reserves 等升级、Legendary Forge 品质上限、Boss Stem Cells 与外观 `[实取]`。
（锻造与 BSC 的逐档数字见 [`external-benchmarks.md`](external-benchmarks.md) 的 §7.3。）

**难度机制**
**Boss Stem Cells 共 5 层**（Hard / Very Hard / Expert / Nightmare / Hell）：
逐层加敌人密度、种类、侦测与瞬移，**砍补血**（隔关喷泉 → 全无 → 全场仅 3 次 → 0 次），
同时**细胞掉落 ×2/×3、物品等级 +1/+3**、开放卷轴碎片与专属门 `[实取]`。

**敌人与 Boss**
敌人池按图与 BSC **分层替换**（Zombie→Rampager、Grenadier→Bombardier），符文由 Elite 守卫；
Boss 是阶段节点（Concierge、Time Keeper、Hand of the King、The Giant 等），
媒体点名**总 Boss 数只有四个** `[实取]`。

**失败代价**
**永久死亡**：一局结束失去局内全部点数、装备、未受 Gold Reserves 保护的金钱与**所有变异**；
保留符文、图纸、已用细胞买下的永久升级、锻造进度、Boss 细胞与已解锁外观 `[实取]`。

**紧张从哪来**
**不能存档的长链条**：一次失误可能抹掉整局 30~60 分钟进度。
低血量、**诅咒箱（拿了就一击必死）**、限时门，
以及高 BSC 让敌人**瞬移到脸上**，共同压缩容错空间 `[实取]`。

**核心取舍**
**每层只能选一张图，选路即选发育**（安全图 vs 高收益图）；
卷轴要不要全堆一色（爆发高但血量薄）；**诅咒箱用一条命换一个卷轴**；
Passage 里有限的细胞投图纸还是投锻造 `[实取]`。

**独有机制**
**"Roguevania"**：把银河城式**永久能力门**（藤蔓/传送/撞墙/贴墙/离体头）塞进肉鸽的随机地图 ——
**能力在局外解锁、局内只改可达性**，等于把"回溯"从单周目搬进整个 roguelite 循环 `[实取]`。

**被称赞**
媒体称手感 `tight controls, satisfying hit feedback`，4Players 称 `beautiful every time anew`，
Polygon 9/10 说 `most fun I've had in a game all year`；Steam 15.66 万条评测中 **97% 好评** `[实取]`。

**被批评**
**重复的关卡设计与 Boss 数量少**（媒体称 `only four in total`）被点名；
GameStar 说早期重复段落 `can feel a bit stale over time`。
另外 **4 BSC 的 Malaise 在 2.3 版被移除**，属官方对难度手感的回调 `[实取]`。

**对 Bronana 的三条**

1. **局外解锁的能力门只改地图可达性、不改数值** —— 地牢按此设 2~3 个永久门。→ **战斗**：
   本作 `dungeon.ts` 的密室与暗门已经是"可达性"，但**没有"局外解锁后才存在的地形"**；
   这一条能把"天赋树的产物只是开局条件"扩到**地图层**（现在只影响开局装备与属性）。
2. **难度层要同时给惩罚与补偿**（掉落倍率、品质上限），并与养成绑定。→ **养成**：
   本作难度阶梯现在**只改敌人**（`danger.ts`），没有"高难度给更多产出"那一半 ——
   对照 BSC 的 `细胞 ×2/×3、物品等级 +1/+3`，这一条是**低代价可直接补**的。
3. **每层只能选一个出口，选路即选发育** —— 营地/据点按此做二选一取舍。→ **经营**：
   本作地牢已有"自己选房间"（`Game.doors()`），
   可对照的是 Dead Cells 把**路线与发育绑死**（选路就是选成长），而不只是选奖励。

### 4. 星露谷物语 / Stardew Valley

**定位**
2D 农场生活模拟 + 角色扮演：以"**一天**"为最小单元，把种地、矿洞战斗、钓鱼、村民社交与社区修复
编织在**同一个时间与体力预算**里 `[实取]`。

**一句话**
用一天的**体力预算**串联农场经营、矿洞战斗与小镇社交的长线生活模拟。

**核心循环**
白天用体力做工具动作（耕地、浇水、砍树、砸石、钓鱼），换取作物、矿石、木材与金币；
金币与物品再投入农场升级、工匠设备与社区中心捆绑包；
社交与技能等级又把同一批产出换成折扣、配方与更高收益，循环回到第二天 `[实取]`。

**单局形状**
以"游戏内一天"为一次会话单元：醒来重置体力 → 白天消耗 → 睡觉结算
（体力恢复量、好感衰减、升级弹窗）→ 次日凌晨继续 `[实取]`。

**每分钟在做什么**
看体力条与时钟决定先做哪件事；每次使用工具扣能量（镐/斧/锄 **2 点起、鱼竿 8 点**）；
吃食物回复体力上限于最大值；体力见底时**体力条抖动**提示。
最大体力 270 `[实取]`。

**一局怎么分段**
**没有"一局"结构**：存档是连续的日与年。矿洞提供分层进度
（120 层、**每 5 层解锁电梯存档点**）；社区中心提供 6 房间 30 捆包的长线清单 `[实取]`。

也就是说"今天升的级，今天用不上" `[实取]`。

**物品设计**
**未取得** —— 抓到的 6 页未给出通用物品稀有度 / 词缀体系；仅见礼物品质与矿石分层出现 `[实取]`。

**局外成长**
金币、社区中心 30 个捆绑包、**5,000 金的 Joja 会员**、
村民好感点数（**每颗心 250 点**）、成就、邮件奖励（工具丢失后次日照邮件返还）`[实取]`。

**难度机制**
矿洞的"危险"档可来自 `Danger in the Deep` 任务与 Shrine of Challenge，
**两者可叠加成难度 0/1/2**；每级怪物生成概率 **+2%**、怪物抗性按倍数、放射性矿 **+0.1%** `[实取]`。

**敌人与 Boss**
1–9 层 Green Slime / Duggy / Bug / Rock Crab；41–59 层 Frost Jelly / Frost Bat / Dust Sprite / Ghost；
81–119 层 Red Sludge / Lava Bat / Shadow Brute / Shadow Shaman / Metal Head / Squid Kid，
危险档另有 Shadow Sniper；**未取得成体系的 Boss 列表** `[实取]`。

**失败代价**
矿洞内昏迷（体力 0 或到 2:00AM）扣 **10% 金币、上限 1000**；
HP 耗尽扣 **5%–25% 金币、上限 15000**，并**随机丢失背包物品（含武器与工具）**
（Galaxy Sword 除外），工具次日邮寄返还、**鱼竿与武器不返还**；可在冒险家公会付费找回 `[实取]`。

**紧张从哪来**
① **体力是一天所有活动的共享预算**；
② 睡太晚、昏迷或力竭会让**次日体力恢复打折**（2:00AM 时 −50%，可叠加）；
③ 跨季节捆包所需材料无法在同一天凑齐；
④ **好感会每日衰减**（−2/天起）`[实取]`。

**核心取舍**
"**今天把体力花在哪**"是每日核心取舍；
社区中心还存在**互斥二选一**：付 5,000 金买 Joja 会员会把社区中心**永久**换成 Joja 仓库，
之后只能花钱买 5 项升级（连 Friendship 这项奖励都不提供）`[实取]`。

**独有机制**
**捆绑包用"超额显示物品 + 有限槽位"表达选择性捐赠**：
Artisan Bundle 显示 12 项但**只需填 6 个槽位**，玩家自行挑选组合，而不是逐项收集清单。

**被称赞**
**未取得（没找到）** —— 抓到的 6 个页面均为规则数据页，没有玩家评价内容可引 `[实取]`。

当天出售或装运拿不到新价格加成；② 矿洞 12/52/92 层的**预设梯子让清怪可被跳过**（页面明确标为 Bug）；

   与星露谷的体力是**同一种形状**；可补的是**跨模块的第二条共享预算**（例如建造也占某个上限）。
2. **战斗轴给"可存读的层间存档点"，同时让死亡掉钱掉物** —— 矿洞每 5 层一个电梯。→ **战斗**：

   星露谷给的第三条路是"**保留进度但扣资源**"，这条对"24 分钟一局"的本作可能比"整局重来"更友好 ——
   ⚠ 但它会削弱 roguelite 的核心张力，**属于设计决策，不是改进**。
3. **社交做成管道而不是终点** —— 好感经捆绑包与信件换成经营资源。→ **养成**：
   本作 `trade.ts` 已把好感做成"交易档位门槛"，与这条一致；

### 5. 潜水员戴夫 / DAVE THE DIVER

**定位**
MINTROCKET 2023 年出品的海洋冒险 + 寿司店经营混合体；Steam **96% 好评、162,947 条评测**，
Metacritic 90，单人游玩。**本节的来源是日文攻略站**（`game.lb-product.com` 与 `himeb.com`），
不是官方 wiki —— 这一点在引用时要记住 `[实取]`。

**一句话**
白天潜入**每次随机生成**的蓝洞捕鱼，夜里用渔获经营寿司店，两条循环互为供血。

**核心循环**
昼：潜水 → 夕方：准备与升级 → 夜：寿司营业 → 翌朝：看销售额，**一天一段**。
渔获是餐厅食材，餐厅收入买装备，装备再让你潜更深、拿更贵的鱼 `[实取]`。

**单局形状**
一天 = 昼 → 夜 → 翌朝三段固定节奏；**单次潜水是数分钟、可随时终止的冒险**，深部更危险。
本篇 30~50 小时 `[实取]`。

**每分钟在做什么**
潜水全程盯**两条表**：**酸素（氧气）** 决定滞在时间与可达深度，**重量上限**决定能带回多少并影响机动。
**氧气耗尽会死，并可能失去所持品** `[实取]`。

**一局怎么分段**
蓝洞**每次地形随机生成**，按深度分水域；大型鱼与 Boss 级生物在深处。

### 8. 露塞提娅：道具屋经营妙方 / Recettear: An Item Shop's Tale

**每分钟在做什么**
柜台前**逐位客人手动出价**：先看对方类型，再按百分比出价，
顾客会砍价或直接走人，**成交越多越容易触发交渉** `[实取]`。

**一局怎么分段**
**地牢按层推进且逐座解锁**：翡翠の道（15 层）、琥珀の庭（30 层）、黒曜の塔（50 层）、
瑠璃の遺跡（100 层）；冒险者需靠**来店事件**与地牢遭遇逐步招揽 `[实取]`。

**操作方式**
**未取得（没找到）** —— 所取页面未记载键位；
只记载**操作导致的隐藏规则**，例如出店后踏入非冒险者公会场所即计 1 格时间 `[实取]`。

**局内成长**
**角色不靠等级成长，而靠名刺/同行与装备**：同一冒险者同行次数最多者在通关时给出**プラチナ名刺**，
可在强くてニューゲーム 开局直接雇用 `[实取]`。

**物品设计**
**出售上限因客而异**：妖精 103%、幼女 113%、盗贼 114%、主婦/老人 116%、
剣士 117%、青年 125%、ギルド 128%、金髪 **148%**；
买取下限从金髪 16% 到妖精 61% 不等 `[实取]`。

**局外成长**
**商人レベル**与店内装潢（壁纸、地板、地毯、货架）可持续投资，
且这些陈设**连同摆出的商品**共同决定店的"**雰囲気（属性）**"—— 地味 / 派手 / 聖 / 魔 `[实取]`。

**难度机制**
**硬压力来自每周固定还款额与时间格经济**：一天内跑太多地点会吃掉可用时间，
而初盘数据 `一発クリアは…不可能` —— **作品本身按多周目设计** `[实取]`。

**敌人与 Boss**
地牢有怪物与各层 Boss；**第 3 座地牢琥珀の庭 若没先看过广场事件，30 层的 Boss 不会出现**。
素材如黑焼き、スライムの肝 需打特定敌人 `[实取]`。

**失败代价**
**破产并非清档**：凑不出钱即 GAME OVER，以 `なんだ夢だったのか` 的轻松方式进入二周目；
**以还款日当晚状态为准，继承全部商品、商人レベル、店内装潢与冒险者状态（名刺需重拿）**，
而所持金、事件、天数、注文、分数清零，**带 1000pix 从第 2 天重开** `[实取]`。

**紧张从哪来**
**还款日是硬截止**：一周内必须凑出指定金额，
于是每一天都在"**今天该开店赚钱还是下地牢补货**"之间被迫取舍 `[实取]`。

**核心取舍**
**议价是即时的双向博弈**：出价过低自己少赚，
过高则对方 `値切られたり呆れて帰ってしまう`；交渉次数越多才能逼近越高的上限 `[实取]`。

**独有机制**
**把讨价还价做成显式数值区间 + 顾客类型阈值**：约 104% 卖、约 70% 买易出 JUST/NEAR PIN，
而 **206% 以上卖出或 28% 以下买取会让人直接走掉** `[实取]`。

**被称赞**

商品还会**高騰・暴落甚至出现ブーム**；而**自动贩卖机则始终按 100% 定价成交** `[实取]`。

仅指出初盘一击通关 `ほどの強運と勘…でないと不可能` `[实取]`。

**对 Bronana 的三条**

1. **用每周期固定还款额做硬倒计时，逾期不清档而是保留资产重来** ——
   压力高但不劝退。→ **经营**：本作**没有倒计时**，跨局是"存钱买设施"的正向累积；

   → **经营 / 养成**：本作 `trade.ts` 是**12 档报价 × 3 位商人**的固定档位，

3. **让店铺氛围（陈设 + 在售商品）决定客层是否到店**，把装修从美术变成**可读的经营参数**。
   → **经营**：本作局内营地是"设施位 + 相邻组合"，**没有"氛围/属性"这一层**；
   这条与 `camp.ts` 的相邻组合是天然可叠加的（相邻产生的不只是数值，还可以是"属性"）。

### 20. Brotato（土豆兄弟）

> **这一节的来源与其他款一样是一手 wiki**，但**数值面另有归口**：
> 单局时长 / 首胜局数 / 敌人涨幅 / 难度档成本见
> [`external-benchmarks.md`](external-benchmarks.md) 的 §1.2 / §4.1 / §6.2 / §7.4 与
> [`scaling-benchmarks.md`](scaling-benchmarks.md) 的 2.1。**本节只写机制。**

**定位**
Blobfish 开发的单机"竞技场生存 + 商店构筑"roguelite；**武器自动开火为默认、可选手动瞄准**，
一局短于 30 分钟，支持本地 4 人合作 `[实取]`。

**一句话**
你不会瞄准 —— 你只走位、捡材料、在每波之间的商店里把 6 个武器槽和一堆道具配成一台机器。

**核心循环**
波次战斗（前 9 波每波 +5 秒，第 20 波 90 秒）→ 波末结算（**Harvesting 属性在这里付息**）→
回收与升级（4 选 1 属性卡）→ **商店**（最多 4 格，可刷新、可锁定）→ 下一波；
打完第 20 波即通关 `[实取]`。

**单局形状**
**20 波封顶**，纯战斗合计 17.5 分钟，加商店约 **25~30 分钟**；第 20 波是终局 Boss 波。
Endless 模式下打完第 20 波还能继续，且**最终死亡仍计为胜利** `[实取]`。

**每分钟在做什么**
**只走位** —— 瞄准与开火是自动的（另有可选的手动瞄准）。
手上真正在做的是"捡材料 + 躲伤害 + 每波结束时读一次货架" `[实取]`。

**一局怎么分段**
一局 = **20 波**：W1 20 秒 → 每波 +5 秒 → W9 起 60 秒 → **W20 90 秒**。
W1–W2 的商店**固定给 2 件武器 + 2 件道具**，W3–W5 保证 1 件武器，
**W6 起不再有任何保证**；稀有度也有门限：**T2 第 2 波起、T3 第 4 波起、T4 第 8 波起** `[实取]`。

**操作方式**
键鼠或手柄；**默认自动开火**，设置里可改成手动瞄准（`Auto-firing weapons by default with a
manual aiming option`）。该 wiki **没有 Controls 页面**（API 返回 `missingtitle`），
所以键位映射是 **未取得（没找到）** `[实取]`。

**局内成长**
升级给 **4 选 1 属性卡**，四档稀有度（Max HP +3/+6/+9/+12 这样的梯度），
**按等级保底档位**（L1 / L5 / L10 / L15 / L20 / L25 各解锁一档）。
另有一条特殊的钩子：**Harvesting 在每波结束时结算**，且**属性自身每波 +5%**（向上取整） `[实取]`。

**物品设计**
**武器与道具两类**。武器有 4 档品质（Common / Uncommon / Rare / Legendary），
**同名同档两把可合成一把高一档**；道具 208 件（+DLC 33 = 241），
**带负面的遍地都是**（`Coffee +10% Attack Speed / -2% Damage`），
另有 **Item Tags**（5% 概率从标签池里选）与 **Curse**（被诅咒的装备数值更强但给诅咒值） `[实取]`。

**局外成长**
**62 个角色里只有 5 个默认解锁**，其余来自三类条件：
难度档（Win a run in Danger N）、**跨局累计**（Kill 300/2000/5000/10000/20000、
Collect 300/2000/5000/10000/20000）、**单局行为**（Die for the first time、
Reach +200 Harvesting、Finish a wave with 1 HP、Get 3 tier IV weapons at once）。
**每个角色首次通关恰好解锁 1 把武器或道具** `[实取]`。

**难度机制**
**Danger 0–5 + Nightmare**，逐级解锁（打赢 D0 解锁 D1 与角色 One Armed，此后每通一档各解锁下一档 +1 个角色）。
修正**写成绝对值且不累加**：D3 +12%、D4 +26%、**D5 +40%** 且双 Boss 各 −25% 生命，
Nightmare +60% 生命/伤害 +10% 速度。无障碍滑条是**乘法叠加**，三项拉满综合难度 **182%** `[实取]`。

**敌人与 Boss**
**屏幕敌人上限 100**，超出上限的敌人随机消失且**不掉落**。
**精英在同一局里不会重复出现**（`Once an Elite has appeared, the same Elite cannot appear again`），
精英掉传奇箱并回 100 HP；兽潮波掉落更少。**第 20 波是二选一的 Boss 波**，
D5 下同时刷 2 个、各 75% 生命 `[实取]`。

**失败代价**
**未取得（没找到）** —— 本轮抓到的页面里没有写"死亡时保留什么"的段落。
可确证的只有：Endless 模式下打完第 20 波后继续，**最终死亡仍计为胜利**；
成就与解锁进度显然跨局保留（见"局外成长"） `[实取]`。

**紧张从哪来**
① **商店的通胀**：刷新价与商品价都是**波次的函数**，且增长率不同 ——
原文 `cheaper items will be hit harder by inflation`，所以"攒钱"本身有隐性成本。
② **第 20 波的时限**（90 秒）与双 Boss 的 DPS 检查。
③ **Harvesting 的复利**：投得越早、到第 20 波差得越远 `[实取]`。

**核心取舍**
**"这一波的钱投产线（Harvesting）还是投战力（武器/道具）"** ——
Harvesting 每波给材料与经验，且**属性自身每波 +5%**，但它**不给你任何即时战斗力**。
第二类是**类别的取舍**：同类 6 把吃满类别加成，但**类别太杂会稀释商店池** `[实取]`。

**独有机制**
**① "武器类别（class）"是一种身份，而且有正反两面。**
17 个类别（Blade / Blunt / Elemental / … / Unarmed），**同类收到 6 把吃满加成**；
商店有 **15%** 概率"匹配你已持有武器的类别"，
但原文同时给出反面：`It can also be detrimental, as holding lots of weapons with different
classes can dilute a shop's pool.`
**② 无敌帧的时长与"这一下打掉你多少血"成正比**：
`Iframe Duration = 0.4s * (percentage of Max HP taken as Damage)/15%`（0.2~0.4 秒），
闪避/格挡只给最小 0.2 秒，**自伤完全绕过无敌帧** `[实取]`。
**③ 角色会让"武器槽"这个数字本身变成变量**：多数 6 把，
但 One Armed 1 把、Multitasker 12 把、**Bull 不能用武器**、Baby 最多 24 把 `[实取]`。

**被称赞**
**未取得（没找到）** —— 本轮抓到的 wiki 正文不含玩家评价；
Steam 商店 API 在本环境可返回官方卖点（含本地 4 人合作与无障碍选项），
但**评测 API 不可达**，故本文不给"玩家普遍称赞什么"的结论 `[实取]`。

**被批评**
**未取得（没找到）** —— 同上：wiki 只写机制与改动史，
评测与媒体原文本环境取不到。**修法与"被称赞"同一条** `[实取]`。

**对 Bronana 的三条**

1. **把"武器类别"做成一条有正反两面的轴**：同类 6 把吃满加成，但类别太杂会稀释商店池。
   → **战斗**：本作已有 `synergy.ts`（武器联动四条轴）与据点的 `depot`（商店必有你在用的类别），
   可补的是**负面那一半** —— 否则"多带几把不同类"没有代价。
2. **让"射程 / 范围"这类属性对某些武器带隐性代价**（近战 Range 只按一半生效且略降攻速）。
   → **战斗**：本作 24 把武器里近战 10 把，可给近战单独一条"射程换攻速"的折法。
3. **无敌帧按伤害比例给，而不是固定时长**（`0.4s × 该下占最大生命的比例/15%`）。
   → **战斗**：让"被大招打中"有更长的恢复窗口；落地是一行公式，属低代价可试项。

### 9. 暗黑地牢 / Darkest Dungeon

**定位**
回合制四人小队地牢探索 + 城镇经营的黑暗哥特 RPG；玩家继承先祖的破败庄园 Estate，
以 Hamlet 为枢纽管理、升级、招募英雄，再派队远征各区域地牢 `[实取]`。

**一句话**
把"**英雄会永久死亡**"做成持续的资源焦虑：压力是第二血条，光照是风险旋钮，
城镇是每周运转的养成机器。

**核心循环**
Hamlet 内消费（升技能、升装备、治怪癖、减压、招募、买补给）→ 编四人队进入远征 →
探索、战斗、扎营、打 Boss → 带战利品与经验回镇。
据点建筑用**传家宝**升级，逐步解锁更高能力与装备等级 `[实取]`。

**单局形状**
以"**周**"推进：每周刷新 Stage Coach 新兵与 Nomad Wagon 饰品；
Abbey/Tavern 减压会**占用该英雄一整周**。
一次远征是一段连续地牢探索，短图不能扎营，中/长图分别自带 **1/2 份免费 Firewood** `[实取]`。

**每分钟在做什么**
战斗按速度轮流行动，选择技能与目标，关注 **1–4 号站位**、血量、压力条、光照与剩余补给；
走廊里点击互动、拆障碍、点灯；扎营时消耗时间来放营地技能（减压、加抗性、做饭） `[实取]`。

**一局怎么分段**
一次任务 = 选区域 + 选任务等级 + 买补给 + 编队 + 进固定地图；清房间与走廊，末尾打 Boss，**可中途撤退**。
任务长度决定免费 Firewood 数量（Short 0 / Medium 1 / Long 2），即**决定能扎营几次** `[实取]`。

**操作方式**
**未取得完整键位**（所抓页面未列）。页面可证的鼠标交互：补给窗口点击购买，**按住 SHIFT 点击买一整叠**；
点击光照计花 1 根火把抬升光照，且**光照只能在当前回合提升** `[实取]`。

**局内成长**
**远征之内不升级**；成长发生在两次远征之间 —— 完成任务得经验提升 Resolve Level，
升级提高抗性并解锁更高技能与装备等级，但**高等级英雄不能再打低等级任务**
（Champion 5–6 级不能进 Apprentice 0–2 级）`[实取]`。

**物品设计**
**饰品每人 2 件**、有正负效果且部分限职业，Nomad Wagon 每周高价出售；
武器护甲在 Blacksmith 按 Resolve 等级升阶。补给有明确单价与"一叠"数量
（食物 75 金/12 一叠、铲子 250 金/4、火把 75 金/8），**回城只按极低价回收** `[实取]`。

**局外成长**
建筑升级用传家宝，且**多数给的是"功能"而非数值**：
Guild 解锁更高技能等级、Blacksmith 解锁更高武器护甲阶、
Sanitarium 解锁治/锁怪癖与更多房间、Stage Coach 扩容并提高新兵等级、Survivalist 教营地技能；
Abbey/Tavern 加房间降费。**Districts 才是少数纯被动收益** `[实取]`。

**难度机制**
四档模式 **Radiant / Darkest / Stygian / Bloodmoon**，同样光照下压力与怪物加成不同；
Stygian 与 Bloodmoon 每探索新区域掉 7 点光（其他 6）。
**0 光照下走廊战有 1%/8%/12%（Apprentice/Veteran/Champion）概率被 Shambler 伏击**。
减压效果**最多只能减 80%**。更高难度下**死太多英雄会直接输掉战役** `[实取]`。

**敌人与 Boss**
0 光照时走廊战可能被 Shambler 伏击；怪物会**专打压力**（如 Swine Wretch、Cultist Acolyte）。
任务等级明确出现 Apprentice（0–2 级英雄）与 Champion（5–6 级），Veteran 被提及但区间未取得。
Veteran 及以上 Boss 掉 Blueprint；Darkest Dungeon 共 4 个任务且**全部必打** `[实取]`。

**失败代价**
**0 HP 不死**，先进入 **Death's Door**，此状态下任何后续伤害都有几率致死。
死亡**基本永久**：饰品掉在原地、只有打赢才能捡回；
唯一复活途径是稀有镇事件 **From Beyond**，复活者**只剩 4 个随机 1 级技能、装备零升级**。
Graveyard 记录每名死者的死因与时间 `[实取]`。

**紧张从哪来**
**压力会滚雪球**：Afflicted 英雄抗命并持续给全队加压，一路把人拖到心脏骤停；
100 点压力还会强制一次"决心检定"。叠加 Death's Door 的随机致死、
低光照对敌人的持续加成，以及**补给用不完只按极低价回收** `[实取]`。

**核心取舍**
钱要花在**补给、建筑升级还是饰品**上；**高光照安全 vs 低光照多掉落与暴击**；
残血英雄再顶一间房 vs 立刻撤退（**撤退本身也加压**）；
把英雄留在 Abbey/Tavern 占一周减压 vs 带他再出发 `[实取]`。

**独有机制**
**压力是第二血条**：0–200 的独立条，到 **100** 时强制判定，
大概率得 **Affliction**（抗命、伤害队友、给全队加压），小概率得
**Virtue**（战斗增益并把压力降到 40–45）；到 **200** 触发心脏骤停，进入 Death's Door 或当场死亡。
**压力不随任务结束恢复**，回镇只被压到 100 `[实取]`。

### 10. 循环英雄 / Loop Hero

**定位**
Four Quarters 开发、Devolver Digital 发行的像素 Roguelike 策略卡牌 RPG；
媒体把它归类为 **"逆塔防"**。世界被巫妖拖入无尽循环，
玩家靠扩充实物卡组为每次循环设定敌人、建筑与地形。

> ⚠ **本节来源全部是中文第三方站点**（第三方拆解文 `gameres.com`、
> 攻略站 `gamemad.com` / `playgame.wiki`、下载站攻略 `gzgztx.com`）。
> **官方 wiki 在本环境抓不到**（`loophero.wiki.gg` 401、fandom 整机不可达），
> Steam 商店 API 两次超时。⇒ **引用时请当"二手资料"，不是一手规格。**

**一句话**
英雄**全自动**沿环形道路绕圈打怪，玩家只负责**往地图上贴地形卡**、并给英雄换装备。

**核心循环**
开局随机生成一条单向环形道路，路上只有营火地块；英雄沿路自动行进。
玩家用卡牌铺地块、换装备；英雄自动战斗、掉落装备与资源。
回营地后用资源建造升级建筑，**解锁新职业 / 新卡牌 / 新系统**，再开下一局 `[实取]`。

**单局形状**
单局制 Roguelike，每局开局**地图与角色状态全部重置**。
玩家在局内被彻底击杀即失败；**击败本局 Boss 即判胜利** `[实取]`。

**每分钟在做什么**
**玩家唯一的手上动作是"铺设地块"与"更换勇者装备"** —— 勇者只按固定路线自动行进，
**战斗为纯自动，玩家没有操作空间**。随机词条装备随手可换；升级时获得**天赋三选一** `[实取]`。

**一局怎么分段**
环形道路 + 局内卡组；开局前选携带的地块牌，**卡组对各类卡牌携带数量有上下限**。
地块分 **5 大类**，按摆放方式区分效果。
左上角第二条（**威胁 / Boss 进度条**）被摆在路上的建筑填满后 **Boss 登场** `[实取]`。

**操作方式**
仅"铺设地块"与"更换勇者装备"两类手动操作。
具体键位映射：**未取得（取不到）** —— Steam 商店 API 两次均超时 `[实取]`。

**局内成长**
击杀小怪得经验，经验满则升级，获得**被动天赋三选一**；
候选从**天赋随机池**抽取，每职业的池含**通用、职业、Boss 三部分**。
装备为战斗掉落的随机词条，随时可换 `[实取]`。

**物品设计**
战斗掉落随机词条装备，可随时更换穿戴以提升英雄属性。
**装备与营地补给品是两条独立强化线**；补给品可针对性强化角色能力，
**携带上限与建筑等级相关** `[实取]`。

**局外成长**
局内资源（材料与补给）**带回营地**做局外养成；建筑**按次序建造**、可继续消耗材料升级增加效果。
建造把"变强"拆成若干小阶段，**每个新建筑解锁一种新卡牌或新系统** `[实取]`。
（逐个建筑的效果见出处表里的 `gamemad.com`：综合训练场解锁特殊天赋、墓穴解锁死灵法师、
庇护所解锁盗贼、墓园升级后可复活勇者。）

**难度机制**
**怪物地块铺得太快太密容易猝死，铺得太慢角色成长跟不上全局强度、最终无法过关** ——
铺设节奏需玩家自己试出来。地图**威胁等级随放置地形卡而提升** `[实取]`。

**敌人与 Boss**
**地形卡本身生成怪物与资源点**。
**Boss 的出现条件是把建筑摆满左上角的第二条进度条，条满 Boss 即来**；
Boss 天赋自成一类候选。四个章节 Boss 各自的登场规则细节：**未取得（没找到）** `[实取]`。

**失败代价**
局内被彻底击杀判失败，**只带出 30% 已获得资源**；
营地建筑升级后可**复活勇者一次** `[实取]`。

**紧张从哪来**
**每次在比较极限的圈数回到营地，玩家都面临抉择**：直接安全撤退结束这一把，
还是再跑一圈拿更大收益。原文评述：
`营火「撤退」机制非常容易激发玩家的赌徒心理，也在一定程度上增加了上瘾性` `[实取]`。

**核心取舍**
**撤退结算按地点分档：营地地块主动撤退带出 100%，非营地地块半途撤退带出 60%**。
原文评述：`选安全撤退的往往觉得自己亏了，选再跑一圈的很可能被打死、得不偿失` `[实取]`。
⇒ 这是本档案里**最干净的一条"收手即收益"设计**，比戴夫的氧气更直接。

**独有机制**
**"逆塔防"**：不同于塔防摆防御塔杀怪，而是**在路径上摆刷怪点让角色去杀**。
以及 **河流地块能使相邻地块的作用翻倍**，但**铺设有一笔画限制**，
玩家会设法**加长河流以覆盖更多景观地块** `[实取]`。
⇒ 这正是本作 `camp.ts` 引用它的原因：**相邻组合是乘法而不是加法，且摆法本身有约束**。

**被称赞**
**多层次且持续不断的成长体验**：每造一个新建筑都解锁一种新卡牌或新系统并应用于之后的局内。
上手成本低、构筑可能性丰富；正反馈"直接且持续"，**没有固定通关公式** `[实取]`。

**被批评**
① **上手理解门槛高**："逆塔防"玩法新颖，但**很难仅靠新手引导让玩家领会"铺设地块对全局的意义"**。
② **击败 Boss 拿到的天赋不要随便解锁** —— 有些用不上、**可能污染天赋池** `[实取]`。

**对 Bronana 的三条**

1. **玩家只做"放地块 + 换装备"两个决策，战斗全自动** —— **动作要少而重**。→ **经营 / 战斗**：
   本作营地正好是"选 3 个设施位 + 摆顺序"，形状与它同源；
   差别是本作把战斗留在玩家手里（`auto` / `manual` 两种）。
2. **河流让相邻地块作用翻倍** —— **相邻组合是乘法不是加法**，且**摆放有约束（一笔画）**。
   → **经营**：本作 `camp.ts` 的相邻组合已是"挨着才生效"，
   ⚠ 但要**确认它是乘法还是加法**：若是加法，这条外部样本说明
   **只有乘法才能让"摆法"成为真正的玩法**。
3. **营地建筑先给"能做什么"再给数值** —— 解锁职业、天赋、新卡牌。→ **养成 / 经营**：
   本作据点已照这条做了（`stronghold.ts` 的 `workshop` / `campSlots` / `freeRespecs`）；
   可补的是**"按次序建造"**这一层（本作据点已有前置链 `req`，与它同形）。

### 11. 双点医院 / Two Point Hospital

**定位**
Two Point Studios 开发、2018 年发售的模拟经营游戏，1997 年《主题医院》的精神续作，
PC / PS4 / Xbox One / Switch 多平台；最后一部 DLC 在 2022 年 3 月。

> ⚠ **本节来源为攻略站**（`ludo.guide` 三页 + 中文攻略站 `doyo.cn`），
> 官方 wiki 在本环境抓不到（`twopointhospital.wiki.gg` 401、fandom 整机不可达）。

**一句话**
玩家当院长：拖地建房间、招人培训、给诊疗定价，看病人沿**接待 → 全科 → 诊断 → 治疗**流动；
**越赚钱声誉越高，声誉越高客流越大，最后被自己造出的排队压垮** —— 这就是它的核心张力。

**核心循环**
补建卡住的环节 → 病人更快确诊治疗 → 收费并涨声誉 → **声誉与医院等级推高客流** →
出现新瓶颈 → 再建房间招人。
原文：`随着聲譽的增長，病人自然會越來越多` —— 同一机制**既是良性循环，也是崩盘源头** `[实取]`。

**单局形状**
以"**一关医院**"为单位，无固定时长；可随时空格暂停、Num +/- 调速。
来源建议 `Play in long sessions` 以盯住全部运营；
本体通关 40–50 小时，全收集 80–120 小时，单个 DLC 再加 12–20 小时 `[实取]`。

**每分钟在做什么**
平移旋转镜头、**拖建房间**、摆设备与装饰、招聘与培训、看病人头顶状态、改价格与政策开关、
处理突发的急诊 / 传染病 / 灾害、把员工从休息室拉回岗位；
**大量时间花在查表格与改布局，而非即时操作** `[实取]`。

**一局怎么分段**
**没有 run 或局内重开**：一关从空地做起，按**一星 → 二星 → 三星**逐级达成目标 ——
一星是基础教学，二星是"治愈 25 個病人和賺錢"，三星追加医院价值目标；
达标即解锁并扩展新医院，关卡线性串成推进 `[实取]`。

**操作方式**
键鼠：**WASD** 平移，**↑↓** 拉近拉远，**Q/E** 或 **←→** 旋转，**R/F** 俯仰；
**空格**暂停、**Num +/-** 调速；**Z/X** 旋转物品，**左 Ctrl** 取消网格对齐，**Delete** 删除；
**1/2/3** 切员工 / 病人 / 疾病列表，**4/5/6** 开财务 / 员工 / 病人概览，**F6/F7** 快速存读档 `[实取]`。

**局内成长**
成长落在"**医院**"本身：买地扩建、加房间与设备、员工升级晋升与培训、机器由勤杂工升到更高等级。
**玩家没有角色等级**；医院等级与声誉上升带来更高价值与更多客流，**同时也就是更大的压力** `[实取]`。

**物品设计**
房间需满足**最小尺寸与内置物品** —— 来源举例全科医生办公室至少 **3×3 用地、一扇门、
一张桌子和一个档案柜**。设备可升级，**机器维护条每接待一个病人约降 10%**（心脏病科 8%）；
**装饰物品提升房间声望** `[实取]`。

**局外成长**
跨关卡解锁：完成目标与记者 / 长官来访等事件给 **Kudosh**，用于换特殊物品；
**研究项目**解锁新房间与机器升级，**培训**解锁技能等级。
**没有跨局数值继承**，进度等于解锁更多房间 / 疾病 / 物品与新关卡 `[实取]`。

**难度机制**
难度由**声誉与医院等级带来的客流**、关卡专属病人倍率、疾病复杂度与突发事件叠加。
来源点名玩家最常见的挫败是 `the snowball effect`：
声誉升 → 客流涨 → 诊断跟不上 → 崩盘；关卡还各有专属倍率 `[实取]`。

**敌人与 Boss**
**不适用**：本作**没有战斗层，也没有敌人与 Boss**。
结构上的对抗对象是**疾病与故障** —— 难诊断的病症、机器损耗、传染病与地震 / 雷击等灾害，
以及由此产生的**排队** `[实取]`。

**失败代价**
失败出现在病人身上：等太久会 **rage quit**、健康持续下降致死，死后**变鬼魂在院内游荡**；
勤杂工可学 Ghost Capture 捕捉鬼魂并小幅加速研究。声誉与治愈率随之下跌。
**医院破产的具体惩罚未取得（没找到）** `[实取]`。

**紧张从哪来**
**张力来自玩家自己的成功**：声誉与医院等级把客流推高，诊断速度与房间数跟不上
（来源称之为雪球效应）；另一条硬性压力来自**传染病** ——
**感染人数一旦超过疫苗数即判定失败** `[实取]`。

**核心取舍**
每笔钱都在多个瓶颈间二选一：先补 GP 还是先补诊断室（**来源主张 1:1**）、
先建治疗室赚钱还是先补厕所长椅保幸福感、要不要贷款、要不要加价、要不要开 Fast Track。
**满意度与利润不可兼得** `[实取]`。

**独有机制**
**核心稀缺资源不是钱也不是地，而是"当下被卡住的那一环"** ——
来源给出的判据极可操作：**GP 门口出现队列，就再建一间 GP 办公室**。
另一个是 **Fast Track 政策**：**确诊度达设定阈值即跳过最后一次 GP 复诊**，
用质量换吞吐量、且是**玩家可开关**的 `[实取]`。

**被称赞**
玩家享受把**自己设计的流水线跑顺**：房间声望达 5 得 **+30% 幸福感**、员工被养成专才、
治愈率与星级一路上升。来源称三星挑战需要抠细节，并建议 `Play in long sessions` `[实取]`。

**被批评**
① 来源直言本作 `micro-management heavy`，三星必须抠细节；
② 玩家最常抱怨**客流雪球造成 GP 长队**，进而病人死亡、rage quit、声誉与治愈率下滑；
③ 社区会用 **The Great Patient Purge** 把病人全遣返救急，**代价是声誉与金钱重创** `[实取]`。

**对 Bronana 的三条**

1. **给每个环节设"排队阈值"，超线即提示补建同型房间** ——
   **核心稀缺资源是"当下被卡住的那一环"**。→ **经营**：
   本作营地的瓶颈是**硬编码的 3 个设施位**（`camp.ts` 的 `slots`），
   缺的是**"哪一环卡住了"的可见反馈** —— 玩家现在要靠自己算，而不是被系统告知。
2. **养成收益写成可见百分比且可叠加**（房间声望 3/4/5 → +10/20/30% 幸福感）。→ **养成**：
   本作据点与天赋的收益多数是"功能"（多一个位子、多几次刷新），
   可补的是**把已有数值型收益写成一条可读的百分比**。
3. **做一个可开关的加速政策，用质量换吞吐量**（Fast Track：达阈值即跳过最后一道复诊）。→ **战斗 / 经营**：
   本作**没有这种"主动放弃质量换速度"的开关**；
   这一类开关正好符合本作"会改行为的东西必须显式选择"的纪律（做设置项，默认关）。

## C · 卡牌与词条

<a id="g-sts"></a>
### 12. 杀戮尖塔 / Slay the Spire

**定位**
Mega Crit Games 的两人团队作品，2017 年 11 月底进入 Early Access 的单机卡牌构筑 Roguelike。
结构口径：一局 3 幕（第 2、3 幕各按同一格式生成），每幕 17 层、7 种节点，
第四幕需集齐 3 把钥匙解锁；Ascension 上限 20；4 名角色（Ironclad / Silent / Defect / Watcher）`[实取]`。

**一句话**
把爬塔做成一张**开局就能预习的分支路线图**：玩家用"走哪条路"而不是"抽到什么"来规划这一局的资源曲线。

**核心循环**
战斗外：普通遭遇给 10~20 金 + 三选一卡牌（有时附赠药水）；精英必掉 1 件遗物、25~35 金、
三选一卡牌且稀有度更高；宝箱给遗物与金币；商人处花金币买卡/遗物/药水并做一次卡牌移除；
休息点选休息（回复最大生命 30%，向下取整）或打铁（升级一张卡）。
打完幕 Boss 后，下一层是给"三选一 Boss 遗物"的专属宝箱，然后进入下一幕并生成新地图 `[实取]`。

**单局形状**
一局由 3 幕构成，每幕 17 层。**地图在点下 Embark 时一次性生成**，但一次只对玩家揭示一幕，
第 2、3 幕各自生成、格式相同。因此单次会话的自然切点是"幕"。**每层最多 6 个房间**、
每房 1~3 条进出连接 —— 这个上限决定了一幕的长度是固定的，**玩家无法靠多走路延长一局** `[实取]`。

**每分钟在做什么**
一分钟大致是 1~3 个玩家回合。玩家看敌人头顶的 **Intents** 决定本回合攻或守，
用基础 3 点能量挑 1~3 张牌打出，再按 End Turn。**手牌上限固定 10 张且不可突破**：
超出的抽牌留在抽牌堆，由效果生成的过量卡进弃牌堆；抽牌堆抽空时把弃牌堆洗回去。
Exhaust 的卡进入消耗堆且除 Exhume 外无法回收，Power 牌打出后直接消失；
X 费牌没有能量也能打出，只是效果为 0 `[实取]`。

**一局怎么分段**
每幕 17 层，层内最多 6 个房间排成大致水平的一行；除最低与最高层外，
每个房间有 1~3 条来自下层的进入路径与 1~3 条通往上层的出口，**只能沿地图上的虚线走**。
固定层：第 1 层全是普通遭遇、第 9 层全是宝箱房、第 15 层全是休息点、第 16 层是幕 Boss、
第 17 层是只放 Boss 宝箱的隐藏层。其余房间按概率随机：
**普通 53%、精英 8%、休息 12%、商人 5%、Unknown 22%** `[实取]`。

**操作方式**
wiki 没有给键位表。已取得的操作口径：玩家在自己的回合里"可以出牌或喝药水"，
出牌消耗对应能量并立即结算，结束回合按 End Turn；**地图界面只能选与当前层有虚线相连的节点**，
不能任意跳层。药水是单次消耗品但**跨战斗保留**。键位、手柄与触屏映射：**未取得（没找到）** `[实取]`。

**局内成长**
四条互相独立的通道。① **能量**：基础默认 3，只能靠遗物改动。② **抽牌**：默认每回合 5 张，
同样靠遗物改（wiki 举 Snecko Eye 每回合多抽 2 张）。③ **卡牌升级**：升级让卡更强，
但**每张卡终生只能升级一次**，主要靠休息点打铁，少数事件与遗物也能升级。
④ **卡牌变形**：结果是"任意稀有度的随机一张卡" `[实取]`。

**物品设计**
四类可持有物：卡牌（攻击/技能/能力/状态/诅咒，稀有度 Common/Uncommon/Rare/Basic/Special）、
遗物（整局永久被动）、药水（单次使用但跨战斗保留）、金币（唯一通用货币）。
**Boss 遗物是最锋利的一类**：只在击杀 Boss（或 Boss Swap）后从三件里选一件，且几乎都带永久代价。
原文例：Ectoplasm `Gain 1 Energy at the start of your turn. You can no longer gain Gold.` ——
给 1 点能量，**永久封掉全部金币来源**，而且它只能在第 18 层之前取得 `[实取]`。

**局外成长**
局外只有一条：**Ascension**。在某个角色上击败任意第 3 幕 Boss 即解锁该角色的 Ascension，
之后开局可开关；在该等级击败第 3 幕 Boss 解锁下一级，最高 20。
**等级是累积的**（每一级包含之前所有修正），而且**每个角色独立推进** ——
可以先把 Ironclad 打满 20 级而 Silent 仍是 0 级。已解锁的等级可任选。
击败腐化之心或进入第四幕**不是**解锁条件 `[实取]`。

**难度机制**
Ascension 20 级，每级一条累积修正：1 精英约多出 60%；2/3/4 普通、精英、Boss 更痛；
5 Boss 战后只回复已损失生命的 75%；6 开局损失 10% 生命；7/8/9 三者更肉且更常获得格挡；
10 开局带 Ascender's Bane 诅咒；11 药水槽 -1；12 第 2、3 幕升级版卡出现率减半；
13 Boss 掉金 -25%；14 Ironclad -5、其余 -4 最大生命；15 事件结果更差、代价更重；
16 所有东西贵 10%；17/18/19 三者招式更刁钻；20 第 3 幕末尾**连打两个 Boss** `[实取]`。

**敌人与 Boss**
普通遭遇分"简单池"与"困难池"：第 1 幕前 3 场、第 2/3 幕前 2 场从简单池抽，其余从困难池抽。
精英必掉遗物；**同一个精英可以在一幕里重复出现但不能连续两次**，并随 Ascension 1/3/8/18 变得更多更强。
Boss 每幕 3 选 1（第四幕只有腐化之心），**行动由头顶 Intents 预告**，多敌遭遇固定从左到右行动。
第 1/2 幕 Boss 给 95~105 金 + 三选一稀有卡，随后一层是给三选一 Boss 遗物的特殊宝箱；
**第 3、4 幕 Boss 不给任何奖励** `[实取]`。

**失败代价**
生命归零即死亡。原文只有一句：`Hit Points (HP): If you run out of HP, you die.`
**在本档案抓到的全部页面里，没有看到任何"死亡后结算局外货币"的机制**：
进度只体现在已解锁的 Ascension 等级与已满足的第四幕钥匙条件上 ——
也就是说**死亡不产生可带走的收益**。生命本身是局内最主要的一维资源：
提升最大生命时会等量提升当前生命 `[实取]`。

**紧张从哪来**
张力来自"**资源换路线**"：金币、生命（归零即死，且休息只能回 30% 最大生命）、
药水（单次但跨战斗保留）三者要同时喂饱一条 17 层的路线。
另有两条结构性紧张：一是**手牌上限 10 张不可突破**；二是**消耗堆除 Exhume 外无法回收**，
所以"打出去"是不可逆的 `[实取]`。

**核心取舍**
最典型的取舍在**休息点**：休息（回 30% 最大生命）与打铁（升级一张卡，而每张卡终生只能升级一次）
只能二选一；由于每幕第 15 层固定是休息点、Boss 前必有休息点，
"我现在血够不够"直接变成路径选择问题。第二类取舍是**事件房**：事件给的是明码代价而非免费奖励 ——
例如 World of Goop 的 Gather Gold（获得 75 金，失去 11 HP）对 Leave It（失去 20~50 金，
且不超过你当前持有量）；Ascension 15 起数字明显变差，Leave It 变成 35~75 金 `[实取]`。

**独有机制**
**把随机地图做成一张可预习的分支路线图**：节点类型在进入前全部可见，玩家用路径规划替代"进门才知道"。
三个关键实现是：① **固定层保底** —— 第 1 层全战斗、第 9 层全宝箱、第 15 层全休息、Boss 前必有休息；
② **Unknown 节点不定型** —— 进房时才决定它是事件/普通/商店/宝箱，某类型没被抽中就把它的概率上调、
抽中后回到基线、换幕全部重置；③ **种子决定全部地图**（各层节点数量与类型、路径拓扑、每幕 Boss），
但同一房间从不同路线进入时内容可能不同 `[实取]`。

**被称赞**
第三方报道（2018-03）记录的口径：Steam 好评率超 95%、销量超 50 万套，
且"不少玩家在游戏里投入的时间超过上千小时"。
可验证的设计侧吸引力是**路线规划与构筑的耦合** —— slaythespire.gg 把每名角色都归纳成三条可执行的雏形：
Ironclad 的 Heavy Blade/Limit Break、Exhaust/Corruption、Barricade/Body Slam；
Silent 的 Poison、Shivs、Footwork 续航；Defect 的 Frost/Focus 长局、Lightning/Claw 速攻、Dark 爆发；
Watcher 的姿态玩法。该站的表述是玩家能 `draft consistent decks, route elites and bosses confidently` `[实取]`。

**被批评**
本档案没抓到系统性的负面评测来源（Steam 商店页与评测 API 取不到，Metacritic 正文被截断）。
能取到的有一处开发者自述的设计张力：Mega Crit 在原型期就架了数据服务器追踪玩家的每个决策，
核心看两个指标 —— "一张卡被挑选的频率"与"它对获胜卡组的影响力"。
**Dual Wield 先是改成"可复制手中最强的任意一张牌"拉升使用率，随后又被削成"只能复制技能卡牌"**，
理由是 `我们不希望玩家们很容易地做到无限出牌` —— 即玩家自制的无限连招与设计预期长期对立。
社区侧的具体批评：**未取得（没找到）** `[实取]`。

**对 Bronana 的三条**

1. **把地牢地图做成"固定骨架 + 概率填充"** —— 第 1 层全普通、第 9 层全宝箱、
   Boss 前必有休息，其余层按 53%/8%/12%/5%/22% 抽。→ **战斗**：
   本作 `dungeon.ts` 已有"死路留给特殊房"，缺的是**固定层保底**与
   **Unknown 节点（进房才知道是什么）**；概率表应登记进声明表 + 启动自检"五项和为 100%"。
2. **在工坊或天赋里各留 1~2 件"有代价的大件"** —— 照 Ectoplasm 那样给一条明确收益
   （每回合 +1 能量）并永久砍掉一条通路（不再能获得金币）。→ **养成**：
   本作道具已有"经济 / 敌人 / 规则"三类代价（`data_items.ts` 的 `COST_KINDS`），
   可补的是**永久封掉某条通路**这一型（现在偏"倍率"）。

   两条明码，并把"同事件结果更差"做成难度档参数。→ **战斗**：
   本作 `story.ts` 已有事件房，这一条是把它的**数值代价**写进声明表而不是散在文案里。

<a id="g-balatro"></a>
### 13. 小丑牌 / Balatro

**定位**
LocalThunk 开发、Playstack 发行，2024 年 2 月 20 日上线 PC 与主机（wiki 主页面记载用 Lua + Löve 开发）。
官方 Steam 简介原文：`Balatro is a deck-building roguelike where you must play poker hands
and earn chips to defeat enemy blinds.`
规模（wiki 主页面口径）：150 张 Joker、15 个牌组 × 8 档难度、22 张塔罗、12 张星球、18 张幻灵、
32 张券、30 个盲注、24 个 Tag `[实取]`。

**一句话**
把扑克牌型压成一条 **Chips × Mult 的乘法算式**，再用 5 个 Joker 槽位去改写这条算式的每一项。

**核心循环**
一局分 8 个 Ante，每个 Ante 三个盲注（Small、Big、随机 Boss）。每个盲注有分数门槛，
玩家有固定手数与弃牌次数，出牌时只结算与牌型相关的牌，得到的 Chips 乘以 Mult 后与门槛比较。
达标进入 Cash Out（基础奖励 + 每剩一手牌 1 金 + 经济 Joker 收益 + 每持有 5 金给 1 金利息，
基准上限 5 金 / 25 金），随后进商店买 Joker、消耗牌、券与补充包，再选下一个盲注。
达不到门槛或没牌可打即本局失败，**必须从第 1 轮重来** `[实取]`。

**单局形状**
8 个 Ante × 3 个盲注 = **24 个盲注**；一轮只在四个界面间流转
（盲注选择 → 打牌 → Cash Out → 商店）。Small 与 Big **可以跳过**，代价是拿一个 Tag 而不是奖励金，
这让"快"成为一种可选节奏；**Boss 盲注不能跳过**。8 个 Ante 打完即通关，
可以选择继续进入 Endless Mode（从 Ante 9 起）。
种子固定的内容包括所有 Boss 盲注、商店内容、抽牌顺序与全部概率掷骰；
用种子开局会关闭收集品解锁与分数统计 `[实取]`。

**每分钟在做什么**
一分钟通常是一手牌到一轮商店。打牌环节从手牌里选**最多 5 张**打出去
（牌型可以随时在计分板左侧预览），必要时先花弃牌次数换手，然后看 Chips 与 Mult 逐项结算。
商店里的动作是：看 2 张随机卡（**Joker 权重 20、塔罗 4、星球 4**）、2 个补充包、1 张券，
然后决定买、卖（售价 = 购买价 ÷ 2 向下取整），或者付钱重掷。
**重掷起始 5 金、每次 +1 金、进新店重置为 5 金**，而且重掷**只换那 2 张随机卡**，
不刷新补充包与券 `[实取]`。

**一局怎么分段**
结构是 Ante → 3 个盲注，而不是空间地图。Small 1 倍基础分、Big 1.5 倍、多数 Boss 2 倍。
Boss 盲注按"**最低 Ante 门槛 + 出场次数最少优先**"随机抽取，
因此同一局内某个 Boss 不会在其它 Boss 出现前重复。Boss 的效果分三类：
给特定牌挂负面状态（debuffed / 背面朝上 / 强制选中）、限制可用的牌型或手牌大小、
改写手牌与弃牌次数以及所需分数。券（Director's Cut / Retcon）可以重掷 Boss，
Joker（Luchador / Chicot）可以关掉它的效果 `[实取]`。

**操作方式**
wiki 未给键位表。已取得的操作事实：打牌环节是"从手牌中选最多五张"构成牌型；
界面支持拖拽 —— `Players can drag the icons of the blinds on the left panel, much like how they
can drag jokers, consumables, and playing cards.`；消耗牌可直接使用。
期间可随时打开 Run Info 查看本局全部牌型的当前等级与 Chips/Mult、当前 Ante 的盲注清单与状态 `[实取]`。

**局内成长**
三条独立通道。① **Joker 槽位与 Joker 本身**：默认 **5 格**，Blank → Antimatter 可 +1 格，
**Negative 版本的 Joker 自带 +1 格**（等于不占格），部分牌组直接改格数
（Painted 只有 4 格、Black 有 6 格、Five-Card Draw 7 格、**Jokerless 为 0**）。
② **牌型等级**：所有牌型从 1 级起，主要靠星球牌升级且**没有上限**，但每局重置 ——
星球牌给对应牌型加固定 Chips 与 Mult，牌型越难加得越多。
③ **牌组改造**：每张牌最多挂 1 个增强、1 个版本、1 个印记 `[实取]`。

**物品设计**
四类物品。**Joker**：150 张，稀有度权重 **Common 70% / Uncommon 25% / Rare 5%**，
传奇只能从 Spectral 的 The Soul 出（出现率 0.3%）。**消耗牌**：22 张塔罗、12 张星球、
18 张幻灵（塔罗与星球 3 金、幻灵 4 金）。**券**：32 张、10 金，效果整局永久，击败 Boss 后补货。
**补充包**：5 类 × 3 尺寸，正常 4 金 / Jumbo 6 金 / Mega 8 金。
价格公式：`buy_cost = (base_cost + edition_cost) × discount_percent`，
`sell_value = floor(buy_cost / 2)`；Joker 基础价按稀有度 1~6 / 4~8 / 7~10 金 `[实取]`。

**局外成长**
主要是解锁与难度阶梯。解锁：150 张 Joker 里 **105 张首局即可获得**，其余 45 张需要满足条件
（`the remaining 45 must be unlocked through the completion of certain conditions`）。
难度：8 档 Stake 累积叠加，且**必须用同一个牌组逐档通关**才能为该牌组解锁下一档 ——
`you must complete the White Stake for the Red [Deck], before you can unlock the Red Stake for the Red Deck`。
牌组共 15 个，另有 20 个挑战牌组，后者只能在 White Stake 玩 `[实取]`。

**难度机制**
两条独立的难度轴。① **Stake**：8 档，每档把之前的修正叠加
（Red 起 Small Blind 不给奖励金，Green/Purple 抬高分数门槛，更高档给 Joker 加
Eternal / Perishable / Rental 标签）。② **Ante 分数台阶**：Ante 1 是 300 基础筹码，
逐幕暴涨到 Ante 8 的 **50,000**，而 Ante 8 的 Showdown Blind 就是通关判据。
无尽模式（Ante 9 起）改用公式计算，wiki 明确其增长
`faster than super-exponential, proportional to x^{x^2}`；到 Ante 39 分数需求超过 2^1024，
**溢出为 NaN（naneinf）** `[实取]`。

**敌人与 Boss**
没有"敌人"，只有**盲注作为关卡门槛**。30 个盲注 = 2 个可跳过的普通盲注 + 23 个普通 Boss 盲注
+ 5 个 Showdown 盲注。Boss 的特殊规则不靠血量而靠**改写规则**：给牌挂负面状态、
限制可用的牌型或手牌大小、改动手牌与弃牌次数及所需分数。选择规则本身就是一条难度设计 ——
`Only the Boss Blinds with the fewest appearances will be selected`，且每个 Boss 有它能出现的最低 Ante。
另有一个兜底 Joker：**Mr. Bones 是唯一能在没达标时不直接输掉整局的手段**，前提是达到需求的 25% `[实取]`。

**失败代价**
达不到盲注分数门槛、或没有牌可打，即本局失败 ——
原文 `the run is lost, and the player must restart from Round 1`。
**局外没有结算货币**：留下的只有收集品解锁与已解锁的 Stake、牌组、挑战牌组。
通关（打完 Ante 8 的 Showdown Blind）会给当时持有的 Joker 盖上所用 Stake 颜色的标签 `[实取]`。

**紧张从哪来**
① **乘法结算的脆弱性**：门槛按 Ante 指数级上涨，而你唯一的分数来源是把 Chips 与 Mult 相乘，
任何一个乘数项没拿到就会被门槛甩开。② **硬上限槽位**：默认只有 5 个，
并且**同一张 Joker 在场上已存在时不会重复刷出**（除非有 Showman），
所以同一家店里同时出现两件想买的东西是常态。③ **稀有度权重本身**：Rare 仅 5% `[实取]`。

**核心取舍**
**"这一局我要堆哪一项"**：加筹码的 Joker 与加倍率的 Joker 往往不能兼得，因为槽位只有 5 个；
扩槽本身也要花一次购买，等于用一件 Joker 的位置换未来的位置。
第二类是**金币的时间价值**：Cash Out 给利息（每 5 金 1 金），所以要现在买还是攒利息；
重掷 5 金起、每次 +1 金，越急越贵。第三类是跳过 Small/Big 换一个 Tag ——
用放弃一轮收入去换一个长期收益 `[实取]`。

**独有机制**
**把构筑强度压缩成一个乘式**：手里的牌与牌型等级给出 Chips 与 Mult，最终分数 = Chips × Mult，
于是"加算的一堆东西"与"一个乘数"在阵容里天然对立。配套三条纪律让这个乘式保持可读：
① **牌型有固定优先级** —— `Higher-tier hands take precedence over lower-tier hands regardless of their level`；
② 只结算与牌型相关的牌（Splash 与 Four Fingers 是例外）；③ 同一个 Joker 不会重复出现 `[实取]`。

**被称赞**
wiki 主页面把 `Run-breaking synergies!` 直接列为卖点，收录的官方 Steam 简介原文也是
`discover new and wild synergies to win!`；游戏里甚至有一项 **`New Game +++`**，
说明"把游戏玩坏"被官方当成**正规玩法**而非漏洞。收集侧同样被设计成驱动力：
200+ 件可收集物、其中 100+ 件可解锁并改善后续局，且每张 Joker 有 5 个版本都要收集。
外部认可：2024 年 TGA 最佳独立游戏 / 最佳独立首秀 / 最佳移动游戏，以及金摇杆最佳独立游戏与突破奖 `[实取]`。

**被批评**
能取到的批评线索是**"与赌博混淆"的顾虑**：官方播客节目页（Game Maker's Notebook，2024-12-09）
明确写到本期讨论了 LocalThunk `the steps he's taking to ensure Balatro is never conflated with gambling`。
随机性争议在社区里也存在 —— 检索到一条 Steam 讨论标题为 `I absolutely hate rng in this game`
（**仅取得标题，正文未取到**）。Steam 商店页与评测 API 本档案均取不到，
所以系统性的负面评价分布与占比：**未取得** `[实取] · [摘要]`。

**对 Bronana 的三条**

1. **伤害结算用 Chips × Mult 两段乘法而不是单一加法**（高牌 5×1 → 同花五条 160×16），
   让"加筹码"与"乘倍率"成为两条独立可投资的轴。→ **战斗**：
   本作的伤害公式可按此拆成两个字段；⚠ 但要先确认它不会与
   `data_items.ts` 的负代价体系打架（同时叠"公式衰减"与"负代价"＝双重惩罚，见 §六 5.1 的④）。
2. **把"构筑格数"做成硬上限 + 代价扩张**（5 格起，Negative 版 +1 格、部分牌组 −1~−2 格）。
   → **养成**：本作的技能构筑槽位与工坊插槽应设上限，并只通过**明确代价**扩容。
3. **商店给"花 5 金重掷、每次 +1 金、进新店重置"这种可反复的低成本决策**，
   并把重掷与补给解耦（重掷不刷新补充包与券）。→ **经营**：
   本作据点已有 `freeRerolls`，可补的是**重掷的递增成本**与"重掷不动某类商品"的区分。

### 14. 最后纪元 / Last Epoch

**定位**
EHG（Eleventh Hour Games）开发的动作 RPG，Steam appid 899770（本档案的 Steam 商店 API 取不到）。
全部数值来自官方支持文档（support.lastepoch.com）与官方论坛（forum.lastepoch.com）。
它是本档案为**词条系统**选定的外部参照：官方口径是**词条 7 档、只有 1~5 档能造**，
一件装备最多 **2 前缀 + 2 后缀**，且档与档的取值区间**不重叠** `[实取]`。

**一句话**
用"7 档词条 + 独立的前后缀槽 + 只能掉落的 T6/T7"把"刷装"和"造装"切成两条都不可替代的路。

**核心循环**
打（战役与 Monolith 的 Echo）→ 掉装备与词缀碎片 → 回锻造台改良已有装备 → 再打。
**Monolith of Fate** 是官方定义的主终局系统：从 End of Time 进入，由多个 Timeline 组成，
每个 Timeline 有固定区域等级、自己的布局/敌人/任务；完成 Echo 累积 Timeline Stability，
达到阈值后可从左上角选择 Quest Echo，三个 Quest Echo 的最后一个就是该 Timeline 的 Boss，
击杀**保证掉落其专属池中的一件**并允许选一个永久 Blessing `[实取]`。

**单局形状**
官方给出的会话骨架是"**Timeline 内的 Echo 链**"：进入一个 Timeline 时从中心岛放出多条路，
每条路上有一个 Echo，完成一个 Echo 会揭示它后面的 Echo，**而已解锁的 Echo 任何时候都能做** ——
所以一段会话是可中断、可回头的。进度计量是 Timeline Stability：累积到阈值就解锁 Quest Echo，
三个 Quest Echo 打完这个 Timeline 即完成。锻造不占会话节奏：
`Crafting using Forge can be done anywhere at any time.`（按 F 打开锻造窗）`[实取]`。

**每分钟在做什么**
进 Echo 清怪 → 捡装备与碎片 → **按 F 开锻造窗决定改哪件**。锻造窗内的动作很具体：
把装备放进顶部槽位，再选一个空的词缀槽并挑一个可用词缀的碎片来加词条，或点击符文图标使用符文，
必要时在 Support Item 槽里配一个雕文。每次动作都消耗 **Forging Potential**，而
`When an item runs out of Forging Potential, you can't alter it further in the Forging Panel.` ——
所以一分钟里真正稀缺的资源是**这件装备还能被改几次** `[实取]`。

**一局怎么分段**
本作**没有"单局 run"** —— 角色持续存在，结构是"战役 → 终局 Timeline"。
Timeline 是一张逐步展开的 Echo 图：中心岛向外多条路，完成即揭示其后的 Echo；
完成 Echo 累积 Timeline Stability，到阈值可以选 Quest Echo，第三个 Quest Echo 是该 Timeline 的 Boss。
每个 Boss 有 4 件专属或套装掉落（2 件常见、1 件随物品稀有度缩放、
**1 件只在 Empowered Timeline 出现**的极稀有），击败后还能选一个永久 Blessing `[实取]`。

**操作方式**
抓到的页面里只拿到两处操作性事实：锻造窗默认**按 F 打开**，且
`Crafting using Forge can be done anywhere at any time.` —— **锻造不是一个地点、不需要回城**。
另一处是物品的组织方式：掉落的碎片先进 Inventory，按下 Transfer Materials 按钮才转入 Material Storage，
而从 Shattering 得到的碎片直接进 Material Storage。键位与手柄支持：**未取得（没找到）** `[实取]`。

**局内成长**
三层。① **被动树**：选定专精后解锁该专精的完整被动树，同时可以把点数投到其它专精树、
但**只能投到"半程的那条链"为止**，且必须先在**一个基础被动树里投满 20 点**才能开始投专精树。
② **装备改良**：锻造走的是"改已有的"而不是"换更好的底子" —— 用碎片往空的词缀槽加词条
或把已有词条升一档（**上限 T5**），用 Rune of Refinement 在档内重掷数值、
用 Rune of Havoc 打乱非封印词条的档位、用 Glyph of Despair 把词条封进独立槽腾出位置。
③ **掉落层**：**T6/T7 只能来自掉落** `[实取]`。

**物品设计**
装备按词条构成分档：Common（无词条）、Magic（1~2 条）、**Rare（3~4 条，最多 2 前缀 + 2 后缀）**、
Unique（有低稀有度不会出现的属性，且**不可被锻造**）、Set（通常 2~4 件）、
**Exalted（含 ≥1 条 T6 或 T7 词条**，T6/T7 无法靠锻造产出但其余锻造规则照常）、
Legendary（在 Eternity Cache 里由 Unique 与 Exalted 合成）。
词条本身有 **7 档，只有 1~5 档能造**，6~7 档必须在掉落时就带着；同一词条每一档的取值是一个区间 `[实取]`。

**局外成长**
骨架是 **Monolith of Fate**：多个 Timeline，每个有固定区域等级、自己的布局/敌人/任务链；
完成 Echo 累积 Timeline Stability，到阈值解锁 Quest Echo，打完第三个 Quest Echo 击杀该 Timeline Boss，
击杀保证掉落其专属池中的一件，并允许选一个给角色**永久增益**的 Blessing。
模式侧只有两档：Normal 与 Hardcore，**两者不共享仓库** `[实取]`。

**难度机制**
两条杠杆都写在官方文档里。① **词条的档位阶梯**：共 7 档，只有 1~5 档能造，6~7 档必须掉落携带；
并且同一词条每档有取值区间，但
`the lowest roll of a tier is always higher than the tier below it` —— **档与档不重叠**，想要更高值只能去刷。
② **Monolith 的 Echo Modifier**：让 Echo 更难但给更多物品稀有度与经验，
作用方式类似 Corruption，区别是**只持续 1~3 个 Echo** 而不是全局；
效果种类多样、不限於加怪物伤害与血量；叠加多个会同时抬高难度与收益 `[实取]`。

**敌人与 Boss**
官方支持文档不收录怪物数据，能确认的只有结构性部分：每个 Timeline 有固定的敌人阵容与任务；
完成三个 Quest Echo 后与该 Timeline Boss 交战，击杀保证掉落其专属池中的一件；
Empowered Timeline 里另有更稀有的专属掉落。
另有一条关于敌人设计的长期线索：EHG 的 Sarno 在 2019 年开了一个名为
`Poorly Telegraphed High Damage Abilities` 的征集帖，明确说目的是
`to review the damage and range of particular abilities`，该帖至今 263 楼、35,200 次浏览 `[实取]`。

**失败代价**
Normal 模式下**死亡没有永久后果**（官方文档未列出死亡惩罚，本档案也未取得相关规则）。
Hardcore 模式的后果是**明确的降级而不是删除**：
`if a Hardcore character dies, it will become a Normal character of the same challenge and Season` ——
角色保留，但离开 Hardcore 的仓库与模式；由于两者不共享仓库，降级后能接触到的物品与原模式是分开的 `[实取]`。

**紧张从哪来**
① **装备本身是消耗品**：每次锻造都吃 Forging Potential，而用尽之后
`you can't alter it further in the Forging Panel` —— 一件好底子上的每次尝试都有机会成本。
② **T6/T7 只能掉落**：锻造的天花板是 T5，于是"造一件接近完美的装备"与"等一件天生更好的掉落"长期并存。
③ **推向极限时的不可逆操作**：Rune of Creation 复制后把**原件与复制品的 FP 都归零**，
Rune of Corruption 会直接锁死后续锻造 `[实取]`。

**核心取舍**
**"升一档"与"改数值"不可兼得**：碎片负责升档，而 Rune of Refinement 只重掷数值、不动档位 ——
玩家要在"把低档词条顶上去"和"把高档词条洗到好数值"之间分配有限的 Forging Potential。
第二类是**槽位取舍**：只有 2 前缀 + 2 后缀，想加新词条往往得先移除或封印一个旧的
（Rune of Removal 移除随机词条，Glyph of Despair 有概率封进独立槽并腾出旧槽，
且**一件装备只允许一个封印词条**）`[实取]`。

**独有机制**
**对"词条"的三条硬约束**，同时钉住随机性与可控性：
① 共 **7 档，但只有 1~5 档能造** —— T6/T7 必须在掉落时就带着，于是"刷"与"造"各有不可替代的产出；
② 一件装备最多 **2 前缀 + 2 后缀**，前缀与后缀是**两个独立的槽位池**，
而不是同一个池子里取并集；③ 同档取值为区间，但
`the lowest roll of a tier is always higher than the tier below it`，**档与档之间不重叠** `[实取]`。

**被称赞**
官方论坛的证据显示玩家最在意两件事。一是**自己能算清数值**：在 Eterra Monthly 的更新说明下，
玩家逐条列出自己推算的收益（`We can expect a 20% DPS boost there`），
并把某个节点换算成 `200% more dmg base from the node and 1100% more damage for the other skeletons
w/o Dread Phalanx`。二是**反馈被真正采纳**：官方新增的 Feedback Forge 章节逐条列出
"你提的、我们改了的"并点名致谢贡献者，玩家回帖直接说 `Top tier new section, love it.` `[实取]`。

**被批评**
① **可见性**：那个 263 楼的征集帖里，玩家原话包括
`90% of the times I die in Arena it's because I get literally 1-shot from full HP by a Soul Spear
from a Hoplite that's outside of my screen` 与
`enemies often have their attack range equal to screen size or even exceed it!`。
② **回归成本**：有玩家反馈离开两年后回来发现 `My passives had been reset. My skill trees had been reset.`。
③ **更新节奏与风险赌博**：Season 4 前的博客下有人抱怨 `waiting 9 months for season 2`，
也有玩家认为 Runes of Corruption 在当前掉落环境下 `prone to provide more frustration then good` `[实取]`。

**对 Bronana 的三条**

1. **词条做成 7 档并保证"低档最高值 < 高档最低值"**（区间不重叠），
   **T6/T7 只从掉落获得、工坊只能做到 T5**。→ **养成**：
   本作 R39 已对齐"档位单调"这一半，可补的是**"造"与"刷"各有不可替代产出**（现在 `roll` 只在生成时调用）。
2. **一件装备用"2 前缀 + 2 后缀"的独立槽位而不是家族并集** ——
   ⚠ 本作**有意**选了并集（R39 写明理由），所以这一条的正确用法是**把它当反面对照**，
   而不是当"行业标准"。要动它，必须先推翻 R39 的理由。
3. **在工坊里给已有词条留 4 种改良手段**（重掷数值、换词条、锁数值、封印词条腾槽），
   并给每次改良一个**有限次数**的预算（对应 Forging Potential）。→ **养成 / 经营**：
   这是本作目前**唯一明确缺失**的一条路径（`roll` 只在生成时调用），
   而"有限次数的改良预算"能让工坊与商店共用同一笔材料的取舍成立。

### 15. 以撒的结合：重生 / The Binding of Isaac: Rebirth

**定位**
俯视角双摇杆射击的地牢 roguelike（房间网格 + 实时弹幕），单人，可本地合作。开发与发行：
Edmund McMillen 与 Nicalis（本轮未从正文抓到发布日与平台列表，故不填）。可确认的版本分层来自
wiki 模板标记：基础版与 DLC 缩写 `nr / a / a+ / r`（Afterbirth / Afterbirth+ / Repentance），
差异在条目中逐条标注（例如 `{{dlc|r}}` 表示仅 Repentance 生效）。

**一句话**
把"一层楼就是一张房间网格"做成核心骨架：清空房间才开门、死路尽头放特殊房、
Boss 房给道具并开下一层的活板门 —— 地图的形状本身就在提示哪里藏着密室与书房。

**核心循环**
进入一层 → 探索房间网格、清空有敌人的房间换掉落 → 找到 Boss 房并击败 Boss →
拿到 Boss 道具池的一件道具与通往下层的活板门 → 进下一层并重复。关门规则写得很直白：
`Isaac cannot leave a Room with enemies until they are all killed or until a door is opened with an explosion.`
清房还会给主动道具充能：`completing a Room with enemies will add one charge`，
四倍大房或 L 形房 `will add two charges`。奖励不是必给的：清房掉落有**掉率累积**机制，
所以循环里同时跑着"找房、清房、赌掉落"三条线 `[实取]`。

**单局形状**
一"局"是从 Basement 1 一路向下打到结局的连续流程，没有回合或时间上限的硬性总分。
结束方式有三种：① 击败当层 Boss 走活板门；② 主动进入需要钥匙/炸弹/血量开启的支线出口；
③ 角色死亡，本局终止。局内有两条被明确写出的**时间门槛**：击败 Mom 用时
`under 20 minutes` 会在 Boss 房墙上裂开 Boss Rush 入口（超时后仍可用 Mama Mega! 等强行打开）；
击败 Mom's Heart 或 It Lives! `in under 30 minutes` 会裂开通往 ??? 层的活板门 `[实取]`。

**每分钟在做什么**
方向键移动、射击键持续输出、按主动道具键、用炸弹开路与炸碎岩石/乞丐/店主。每进一个有敌人的房间，
门会锁死，必须在房间内边跑位边清怪，清完才恢复通行；进 Shop 或 Treasure Room 要先掏钥匙开门。
非战斗时间花在"筛图"上：判断哪条死路可能是 Treasure Room、Shop、Library、Vault 或 Dice Room，
决定这层还剩的钥匙与炸弹投给谁。门锁有防卡死例外，但
`This will not occur if Isaac has flight or if there is a boss or miniboss in the Room.` `[实取]`

**一局怎么分段**
一局按楼层（Floor）→ 章（Chapter）→ 结局层分段。每层是一张程序生成的房间网格，
按权重随机塞入若干 Special Rooms，正文逐一列出的类型有二十余种（Boss Room、Treasure Room、
Planetarium、Shop、Arcade、Challenge Room、Curse Room、Sacrifice Room、Secret Room、Devil Room、
Angel Room、Vault、Dice Room、Crawl Space、Boss Rush 等）。特殊房不是均匀乱撒：
Boss Room 取离起点最远，Secret Room 邻 3~4 间，Super Secret Room 只邻 1 间非特殊房且靠近 Boss 房 `[实取]`。

**操作方式**
键盘/手柄的移动 + 射击双输入（射击可用方向键独立瞄准），另有主动道具键与炸弹键；
地面可有水/血/岩浆的水淹房，并与部分道具产生特殊互动。关键设计点是**门是一个输入约束而不是纯数值**：
炸弹可以当作开门工具（`until a door is opened with an explosion`），
因此爆炸物同时是输出、资源采集与通行手段。移动能力会改变危险交互 ——
例如 Curse Room 门刺 `Isaac doesn't take damage upon entering the room if he has flight (still takes damage upon exiting)` `[实取]`。

**局内成长**
不是等级而是**道具累积**：房间、Boss、商店与 Devil/Angel 房都能拿到被动道具并立刻生效，
频率约等于"每清几间房 + 每层一个 Boss 道具"。关键是**同一属性用非线性公式叠加**，
边际收益递减。公式原文：
`EffectiveDamage = (CharBaseDmg × √(TotalDmgUps × 1.2 + 1) + FlatDmgUps) × Multipliers`；
条目算例：第一个 Pentagram 让以撒伤害变 3.5 × (1 × 1.2 + 1)^0.5 = 5.19，第二个只加到 6.45，
即 `a 1.26 increase instead of a 1.69 increase` `[实取]`。

**物品设计**
被动无上限累积，主动占一槽并用清房充能。稀有度用**道具池**区分来源（Treasure Room pool、
Boss pool、Devil Room pool、Angel Room pool、Curse Room pool、Planetarium pool、Library 等）。
代价最鲜明的是 Devil Deal：**以红心上限购买** ——
`All items normally cost either 1 or 2 Red Heart Containers, and their prices roughly correspond to their power.`，
没有红心时改收 3 个魂心。合成不是同名合成而是**乘算叠加**：多个倍率相乘
（Proptosis × Eve's Mascara = ×4），但三个 1.5× 来源不叠加，只取其一 `[实取]`。

**局外成长**
走"解锁"而不是"数值喂养"：达成条件解锁新角色、新道具进入道具池、新结局与成就。
Hard mode 条目给了一整张 Unlocks for Hard Mode 表 —— 每个角色在 Hard 下击败 Mom's Heart
解锁一个 co-op baby，集齐全部 completion marks 再解锁第二个；The Lost 的 all-marks 奖励是 Godhead，
全部非 Tainted 角色是 Mega Mush，全部角色（含 Tainted）是 Death Certificate `[实取]`。

**难度机制**
① **Hard mode 是开局选择的模式**，HUD 上出现 `a small red pentagram`。差异逐条：
`2-3 more rooms generate each floor`、难度为 1 的普通房被排除或降权、
敌人 `have a base 20% chance to become Champions instead of only 5%`、
Champion 只有 33% 而非 100% 给掉落、清房掉心被砍 66%（Repentance 为 34%）、
`Floors are more likely to have curses`、Slot Machine 出奖率减半、Beggar 至少 6 次捐赠才给东西、
Repentance 下商店有 50% 概率降级。② 另一维是层数与章：越深越难，
特殊房类型会在特定章之后停止出现 `[实取]`。

**敌人与 Boss**
分普通怪、Champion（精英）与 Boss / Mini-Boss。Champion：普通 5% 变、
Hard 下 20%，且只有 33% 概率给掉落。Mini-Boss Room 固定是七宗罪之一，且进门即被封死，
`unable to be escaped or opened, even by explosions`。Boss 房每层一个、按离起点最远生成，
胜利给 Boss 道具池一件 + 按难度给心 + 活板门；Krampus、Mega Satan Arena、Mother Arena、
Boss Rush（2/4/8 个底座二选一并摧毁其余）是额外 Boss 内容 `[实取]`。

**失败代价**
死亡即本局结束：局内累积的道具、被动加成、地图探索、未使用的钥匙与炸弹全部作废。
跨局保留的是解锁与成就，属账号级进度而非角色属性。有一条被明确写出并成为 Devil Deal
核心风险的规则：花光所有红心上限不会立刻致死，只要还有魂心/黑心/骨心 ——
`Spending all of his Heart Containers will not kill Isaac as long as he has Soul Hearts, Black Hearts, or Bone Hearts remaining.`
反之，拿 Deal 时把血量清到零、还能靠持有的主动道具或 Dagaz 当场补心，也能活下来 `[实取]`。

**紧张从哪来**
① 门锁：进房即被锁在与敌人的封闭空间里，小 Boss 房连爆炸都炸不开。
② **清房掉落是可变比率奖励**：起始掉率仅 `(1+[coolness]-[curse])%`，每间空手清房约 +9%，
上限 85%（首层）或 80%（其他层），一拿到奖励就重置回起点，让"再清一间"持续有拉力。
③ 恶魔房的代价与掉率惩罚联动，且
`Once a Devil Room door closes for the floor, it cannot be re-opened without picking up Goat Head or Eucharist.` `[实取]`

**核心取舍**
**地图资源投给谁**的三选一，可点数且不可回退：钥匙 → Treasure Room / Shop / Library / Vault / Dice Room；
炸弹 → Secret Room / Super Secret Room / Bedroom（需两颗炸弹）/ 岩石与店主乞丐；
红心上限 → Devil Deal 的 1~2 颗心，代价是放弃后续所有 Angel Rooms
（`Angel Rooms will not spawn for the remainder of the run`）。
所以玩家实际是在"Devil Deal 的即时强道具"与"保留 Angel Room 资格 + 留住红心"之间选。
次一级取舍是隐藏房位置：炸弹数量决定这层能验证几个假设 `[实取]`。

**独有机制**
**"死路即特殊房"的房间图生成规则与它的反向利用**：玩家靠房间拓扑反推隐藏内容的位置。
硬约束：Secret Room `usually surrounded by 3 or 4 Rooms`；
Super Secret Room `only located next to one other non-special Room` 且 `tend to spawn closer to the Boss Room`；
Boss Room `typically spawn in the room that's as far from the starting room as possible`。
Red Room 还有边界：只能在以中心房为准 13x13 的范围内生成。
这些规则让地图本身成为**可推理的信息面板**，而不只是一张随机图 `[实取]`。

**被称赞**
本轮从正文里能确认的、被设计者当正价值强调的点是**非线性叠加与视觉反馈**：
Damage 条目评述 `This formula makes most damage upgrades less potent the more that Isaac has.`；
同时条目解释了道具尺寸的视觉冗余设计 ——
`As damage increases, the size of the tears increases as well. However, tear size is not always a direct indication of how much damage tears will do`。

故不引用、不代写 `[实取]`。

**被批评**
本轮从正文里能确认的批评只有**游戏自身承认的缺陷与异常**：
① Damage 条目承认伤害缩放使多数伤害提升 `less potent the more that Isaac has`（算例见上）。

后续 roll 都被限制在该标签内，并破坏 Tainted Lost 的道具排除机制。
③ Rooms 条目承认需要防卡死补丁：不可触及敌人时门会自动打开。

**对 Bronana 的三条**

1. **特殊房用拓扑约束而不是纯权重来放** —— Secret Room 必须邻 3~4 间、
   Super Secret Room 只邻 1 间非特殊房且靠近 Boss 房、Boss 房取离起点最远，都是硬条件。
   → **战斗**：把这三条写成生成期的硬断言，玩家就能靠地图形状反推隐藏内容的位置，
   随机地牢才会被读懂而不是被忍受。
2. **给清房掉落加一条会累积、命中即重置的概率轨道** —— 以 `(1+coolness−curse)%` 起步、
   每间空手清房约 +9%、上限 85%/80%，掉出奖励就回到起点。
   → **战斗**：连续几次空手不会让玩家判定系统坏了，反而推动他"再清一间"。
3. **把一次性代价与永久资格绑在同一次选择上** —— 拿 Devil Deal 立刻变强，
   但本局 Angel Room 资格永久消失。→ **经营**：用不可逆的资格损失做取舍，
   比单纯扣数值更能制造决策重量，局内营地与据点的资源分配才会有记忆点。

<a id="g-gungeon"></a>
### 16. 挺进地牢 / Enter the Gungeon

**定位**
俯视角双摇杆射击的地牢 roguelike（弹幕 + 房间网格），支持单人与本地双人 co-op。
开发：Dodge Roll（Lead Designer Dave Crooks、Lead Programmer Brent Sodman 与 David Rubel、
Lead Artist Joe Harty）。发行方、发布日期与平台清单本轮**未取得（没找到）** ——
wiki 的 Dodge Roll 条目只列出作品年份（Enter the Gungeon 2016、Exit the Gungeon 2019、
House of the Gundead 2020），未给具体发售日与平台。可确证的版本分层来自条目内的更新名：
Supply Drop、AG&D（Advanced Gungeons & Draguns）、A Farewell to Arms、Payday Update。

**一句话**
把"子弹地狱"和"塞尔达式地牢"焊在一起：几乎所有威胁都是能被翻滚穿过的弹幕，
于是玩家的核心技能不是数值而是判断 —— 一次翻滚约 0.7 秒，前半段完全免疫伤害，
后半段继续移动但会照常吃子弹，且出手后不能改变方向。所以"什么时候不该滚"比"怎么滚"更重要。

**核心循环**
进入一层 Chamber → 在房间网格里战斗、开箱、用钥匙与炸弹换资源 →
找到该层 Boss 并击败它（Boss 必定给武器或道具、Hegemony Credits 与 1~3 个心/弹药/钥匙）→
通过 Boss 后的通道下到更深一层并重复。叙事目标写在 The Gungeon 条目里：
探险者来找的是 `a Gun That Can Kill The Past`。
循环里另一条并行线是"清房 → 掉宝"，而清房给的奖励概率会被 Curse 拉低 `[实取]`。

**单局形状**
从 Chamber 1 杀到 Chamber 5（Forge）并面对 High Dragun 的连续流程，中间可以拐进隐藏层
（Oubliette、Abbey of the True Gun、Resourceful Rat's Lair、R&G Dept.），或直达 Chamber 6 Bullet Hell 找 Lich。
结束方式：击败 Boss 后若持有 Gun That Can Kill The Past 可以进入自己角色的 Past 打最终一场，
或继续下潜直到死亡。隐藏层入口的具体触发条件本轮**未取得（没找到）**逐条正文 `[实取]`。

**每分钟在做什么**
一边走位一边持续射击，用右键（键鼠）或 LB（手柄）做 dodge roll 穿弹，翻桌把桌子当掩体、
换枪、用 Blank 清屏、开箱与捡资源。硬事实：一次翻滚 `lasts about 0.7 seconds`，且
`the player cannot change their movement direction after committing to a roll`；
键鼠 `can only dodge roll in the 8 cardinal directions`，手柄则有 360° 方向控制。
翻滚撞敌造成 3 点伤害（The Robot 为 4） `[实取]`。

**一局怎么分段**
按 Chamber 分段，每层是一个房间网格加一个 Boss 房，另有一层起就存在的支线门。
正文列出的完整结构：The Breach（非 Chamber 的安全前厅）→ Halls of Knowledge（Chamber 0，教程）→
Keep of the Lead Lord（1）→ Oubliette → Gungeon Proper（2）→ Abbey of the True Gun →
Black Powder Mine（3）→ Resourceful Rat's Lair → Hollow（4）→ R&G Dept. → Forge（5）→ Bullet Hell（6）。
每层布局会重排，而 Breach 与 R&G Dept. 被明确写成不重排 `[实取]`。

**操作方式**
键盘鼠标或手柄；移动与射击方向分离（双摇杆式）。dodge roll 默认绑定键鼠 `Right Click` 与手柄 `LB`。
设计上被点名的细节：翻滚前半段 `the player is invulnerable to all damage and will not connect with enemy projectiles`，
后半段 `continues moving but becomes vulnerable to gunfire`，即**无敌帧只覆盖半程**，
条目原话是 `a valuable but inherently risky method of avoiding damage`。
翻滚还能灭火并免疫尖刺、goop 与坑等地面危险，机制命名参考 Stop, Drop, and Roll `[实取]`。

**局内成长**
以"拿到武器与被动道具"为主，拾取即生效，没有经验等级。频率较高：Boss 必给一件随机品质的武器或道具，
宝箱在 Reward 房与清房掉落中提供更多，商店与 NPC 用金币或钥匙换装备。成长带明确的**弹药与携带约束**：
每把枪有独立弹药，道具与主动道具占各自槽位，玩家要在"多带一把枪"与"带一件保命道具"之间反复权衡。
一批道具直接把翻滚变成输出或资源通道：Easy Reload Bullets 让翻滚上膛一发、Roll Bomb 让翻滚掉炸弹、
Rolling Eye 让翻滚把敌人子弹反弹回去 `[实取]`。

**物品设计**
稀有度用箱子颜色表达：Brown (D)、Blue (C)、Green (B)、Red (A)、Black (S)。品质频率随层迁移 ——
`chances for higher quality chests increasing on later floors`，并可切换到两套 loot table
（Gungeons and Draguns 与 Classic）。正负代价来自三条：带诅咒的枪与道具提升 Curse；
打破箱子换劣质掉落，权重表为 Junk 0.6、半颗心 0.2、爆炸 0.1、随机道具或枪 0.1；引信箱不快点开就炸成空。
合成是协同（Synergy），Synergy Chest 约 5% 出现在 Reward 房 `[实取]`。

**局外成长**
集中在 The Breach，货币是 **Hegemony Credits**（HC，Boss 掉落，无伤通过给双倍）。
解锁的是功能与内容而非纯数值：Acquisitions Department 的 Ox and Cadence 用 HC 卖大量物品解锁；
Sorceress's Room 花 6 HC 进 Blessed Mode、6 HC 进 Challenge Mode（尝试 30 次后降到 1 HC）、
免费进 Turbo 与 Rainbow Mode；Professor Goopton 与 Trorc 各开一家主题商店。
Elevator Room 由 Tailor 修电梯，修好可直通前四层，四部全修好后免费开放 Boss Rush ——
`This is the only way to enter Boss Rush.` `[实取]`

**难度机制**
两层叠加，不靠单一开局档位。① 层数本身：Chamber 越深，敌人血量与伤害按各层 health scaling 倍率缩放。
② **诅咒是玩家自选的难度旋钮**：越高出现越多 Jammed 敌人，10 点诅咒会召出打不死的 Lord of the Jammed
持续追击。③ 可购买的挑战模式放在 Sorceress's Room：Blessed、Challenge、Turbo、Rainbow，
且 Challenge Mode 有代价 —— `this room will become boarded up, preventing the player from using shortcuts.` `[实取]`

**敌人与 Boss**
Boss 每层末尾一只，五层各三选一（Keep: Bullet King / Gatling Gull / Trigger Twins；
Proper: Ammoconda / Beholster / Gorgun；Mine: Cannonbalrog / Mine Flayer / Treadnaught；
Hollow: High Priest / Kill Pillars / Wallmonger；Forge: High Dragun），
另有隐藏 Boss（Blockner、Door Lord、Blobulord、Old King、Resourceful Rat、Agunim、Lich）与 Past 专属 Boss。
**所有 Boss 都有逐层递增的 DPS 上限以阻止秒杀**，上限在 Boss Rush 中取消。
普通敌人有 Veteran 变体，其精英化形式即 Jammed `[实取]`。

**失败代价**
死亡结束本局：局内的枪、道具、弹药、钥匙、金币与本层地图进度全部作废，回到 The Breach 重新出发。
跨局保留 Hegemony Credits、已解锁的 NPC/商店/模式/捷径与成就进度 —— **解锁是永久的，属性不是**。
一条重要的保留规则写在 Bosses 条目里：进入自己的 Past 时（Pilot 除外）
`they will lose their items and guns, but will keep blanks and armor`；
The Robot 的 Past 里护甲固定重置为 6，少数道具例外地会带进 Past `[实取]`。

**紧张从哪来**
① **翻滚是半程无敌**：前半段完全免疫弹幕，后半段只免疫接触伤害且照常吃子弹，出手后还不能改方向 ——
压力不是"有没有翻滚"而是"这一滚会不会把自己送进更糟的位置"。
② 诅咒是滚雪球式自我加压，而来源里有偷店（+1）与祈祷 Ammo Shrine（+3.5）这类**主动选择**；
到 10 点，Lord of the Jammed 出现且 `It cannot be killed, and continually chases the player.`
③ 宝箱带引信，逼玩家在战斗中做资源决策 `[实取]`。

**核心取舍**
**钥匙与炸弹在"确定收益"和"未知但可能更强"之间的分配**：宝箱分 D/C/B/A/S 五色，
而 `On every floor, one treasure room chest will contain a gun while the other will contain an item` ——
玩家知道自己至少需要一把枪，但哪个箱子是枪是随机的。第二层取舍是打箱子还是开箱子：
开枪打破立刻拿东西，但权重表显示 Junk 占 0.6。第三层取舍由诅咒量化：
+2 诅咒的 Casey 或 +5 的 Finished Gun 同时买下更高的 Jammed 概率与更低的清房掉率 `[实取]`。

**独有机制**
**dodge roll 的"半程无敌帧"** —— 同一个动作里约 0.7 秒的前一半完全免疫弹幕，
后一半只免疫接触伤害且照常吃子弹，并且出手后不可转向。它把弹幕回避从纯反应问题改造成**承诺问题**：
条目把掌握它的定义写成否定式 —— `effective mastery of the dodge roll includes knowing when not to use it`。
另一条独有设计是**诅咒的双向账本**：Curse 同时提高敌人强度、Jammed 概率、Mimic 与引信箱概率，
以及清房给弹药的倍率（x1.05 起、逐点升到 x1.50） `[实取]`。

**被称赞**
正文里能确认的"被称赞"只有开发者自陈的设计理由。dodge roll 是继射击后第二个加入的机制，
Dave Crooks：`The dodge roll is the first mechanic other than shooting that went into the game.
When we discussed merging a bullet hell game with a dungeon crawler, we immediately started talking
about hot to 'pull an Ikaruga' - or otherwise give the player a way to deal with the massive amount of bullets,
that wasn't just weaving through them.` `[实取]`

**被批评**
本轮从正文里能确认的批评只有**开发者自陈的取舍与已修的问题**：dodge roll 的无敌帧来自移植 ——
`The entire team counts Dark Souls among their favorite games, and including the i-frame laden dodge roll
from the Souls series was an early suggestion.`；另一条是对随机性的自我修正：Rusted Key 在 Anniversary
更新前的稀有度算法 `used a formula similar to the lottery tickets analogy`，之后改成固定产出大箱等值。
玩家口碑与媒体批评类原文本轮**未取得（没找到）** `[实取]`。

**对 Bronana 的三条**

1. **把回避动作拆成有代价的承诺而不是免费按钮** —— 翻滚总长约 0.7 秒、前一半完全无敌、后一半可被打中、
   出手后不能改向。→ **战斗**：把翻滚时长、无敌窗口与落地硬直做成三个可调数值，
   而不是一个笼统的"闪避"按钮，调数值时能直接看出是哪一段窗口在影响手感。
2. **让同一根负面状态条同时带正收益** —— Curse 提高敌人强度与 Mimic 概率，却把清房给弹药的倍率
   从 x1.05 抬到 x1.50。→ **养成**：词条用"风险条换资源产出"的双向账本，
   比纯减益更能驱动玩家主动加码；但必须让正面出口可观测，否则玩家只会一律回避。
3. **把难度做成可用代币购买的多种模式而不是一条线性档位** —— Blessed 与 Challenge 各 6 HC、
   Challenge 尝试 30 次后降到 1 HC，且 Challenge 会封掉捷径作为代价。
   → **经营**：让跨局据点卖"玩法变体"而不是数值加成，据点商店每次刷新都值得看一眼。

### 17. 雨中冒险 2 / Risk of Rain 2

**定位**
3D 第三人称射击的 roguelite；玩家操控 Survivor 在开放环境里跑图，单人可玩，也支持多人合作，
且多人会改变难度与掉落（正文明确写入 `playerCount` 对难度系数与传送器充能的影响）。
开发与发行、发布日期、平台清单本轮**未取得（没找到）** —— wiki 正文不含这些字段。
可确证的版本与资料片分层来自条目内的缩写标记：`SotV`（Survivors of the Void）、
`SotS`（Seekers of the Storm）、`AC`（Alloyed Collective）。

**一句话**
把"时间"本身做成难度条：难度系数随时间线性上涨、每完成一个环境再乘 1.15，
敌人按等级套 30% 生命与 20% 伤害，于是玩家的真正对手是"跑得够不够快"而不是某一只 Boss；
而成长手段是**同名道具无限叠加**，叠加分线性 / 双曲 / 倒数 / 指数四种形状。

**核心循环**
进入一个 Environment → 打怪攒金币、找箱子与神殿（花金币换道具）→ 找到并激活 Teleporter
开始 Teleporter Event → 在红圈内清掉 Teleporter Boss 并把传送器充能到 100% →
领一份 Uncommon 道具、传送去下一个环境并重复。每完成一个环境，难度系数就永久乘一次 1.15，
所以循环每转一圈不只是变强，同时也在把之后每一圈的敌人推高。最终目标由 Primordial Teleporter
决定：与月球对齐去 Commencement 打最终 Boss，或与星球对齐开始 Looping `[实取]`。

**单局形状**
一"局"没有回合上限，长度由玩家自己决定（可以一直 Looping），结束点是死亡、通关 Mithrix，
或因难度失控而死。单圈的时长被传送器硬性框住：所有存活玩家全程待在圈内时，
充能 `charges in a minimum of 90 seconds`。充能速度按圈内人数比例计算 ——
`If all players are in the radius, it charges at 100% speed. If 2 out of 4 players are in the radius,
it charges at 50% speed.` 充能到 99% 时该环境停止自然刷怪，且**不要求先打死 Boss** `[实取]`。

**每分钟在做什么**
边跑图边清怪、边找箱子与神殿，随时盯着右上角难度条与计时器，决定何时按上传送器。
移动与生存是 3D 空间里的跳跃、冲刺与走位，技能由 Survivor 决定。
有一条被明确写出的探索摩擦与它的补丁：传送器 `always attempts to spawn far away from the player's
spawn location`，且有些位置难找，为此它会 `emits slow-moving glowing orange particles that can be seen
from a distance`，更新记录还专门把粒子半径从 38 提到 60 `[实取]`。

**一局怎么分段**
按 Environment（Stage）分段，每段一张开放地图加一个传送器，段与段之间通过传送器串联。
段落有叙事终点：Sky Meadow 与 Helminth Hatchery 放的是 **Primordial Teleporter**，
需用外圈环对齐月球（去 Commencement）或对齐星球（Loop 回第一段）。除主线外还有 Orbs & Portals 支线：
Blue Orb（Newt Altar）→ Bazaar Between Time；Golden Orb（Altar of Gold）→ Gilded Coast；
Celestial Orb（首圈后的第三段固定出现）→ A Moment, Fractured；Purple Orb → Void Locus。
多个 Orb 可挂在同一传送器上，但只能选一个门走 `[实取]`。

**操作方式**
3D 第三人称：键盘鼠标或手柄，移动 + 跳跃 + 四个技能键（Primary / Secondary / Utility / Special）
加一个装备（Equipment）键。装备是"主动道具"，全局限一个槽 ——
`A player can normally hold only one active item at any time; if they try to pick up an active item
while they are already holding one, they will swap it for the new one instead.`
局内是否需要手动瞄准取决于 Survivor，正文没有给出自动攻击类设定，故不写 `[实取]`。

**局内成长**
完全由**道具叠加**驱动，叠加方式被分成四种，这决定了成长曲线的形状：
线性 `f(x)=1+a·x`（Soldier's Syringe +15%/层）；双曲 `f(x)=1−1/(1+a·x)`
（Tougher Times 十层为 60% 而非 150%）；倒数 `f(x)=a/x`（层数越多单层越弱）；
指数 `f(x)=a^x`（Shaped Glass，2 层把伤害翻 4 倍、生命除 4，因为复利）。
正文点出指数叠加的意义：`going from 5 to 6 Shaped Glass would make the damage bonus increase
from +3200% to +6400%`。叠加一般受 32 位整数上限限制，Focused Convergence 硬上限 3 层 `[实取]`。

**物品设计**
稀有度用边框颜色表示：White/Common、Green/Uncommon、Red/Legendary、Yellow/Boss & Planet、
Blue/Lunar、Purple/Void，另有 Meal 与 Equipment。正负代价集中在 Lunar 与 Void 两档：
Lunar `characterized by their powerful abilities, at the cost of having considerable drawbacks`，
不能从箱子出，只能用 Lunar Coins 买；Void 道具会**腐蚀**对应道具 ——
例如身上有 3 把 Tri-Tip Dagger 时拾取 Needletick，会变成 4 把 Needletick 且 Dagger 归零。
改造走 3D Printer `[实取]`。

**局外成长**
走"解锁 + 图鉴"，不喂养数值：`Some items need to be unlocked by completing a Challenge to appear in game.
Pick up an item to unlock its logbook entry.` 怪物图鉴同理：任何怪物有 1% 概率掉 Monster Log
（Boss 为 3%），前提是队伍里还没人有该条目。永久解锁内容还包括 Survivor 与其 alternate skins
（mastery 挑战只能在 Monsoon 完成）。货币有 Gold（局内、随难度系数膨胀）与 Lunar Coins；
正文**未说明** Lunar Coins 是否跨局持久，故不写 `[实取]`。

**难度机制**
① 开局的 Initial difficulty：Drizzle / Rainstorm / Monsoon。Drizzle 让时间以正常速度的 50%
影响难度、玩家护甲 +70、生命恢复倍率起始 1.5；Monsoon 让时间为 150%、生命恢复起始 0.6。
② Scaling difficulty 由全局 **difficulty coefficient** 驱动：
`playerFactor = 1 + 0.3 × (playerCount − 1)`；
`timeFactor = 0.0506 × difficultyValue × playerCount^0.2`；`stageFactor = 1.15^stagesCompleted`；
`coeff = (playerFactor + timeInMinutes × timeFactor) × stageFactor` `[实取]`。

**敌人与 Boss**
敌人按等级缩放，`enemyLevel = 1 + (coeff − playerFactor) / 0.33`，且 `enemies always start at level 1`；
每升一级敌人获得 **30% 生命与 20% 伤害**。刷怪由 Directors 管理：随时间累积 credits，
弱怪便宜、Magma Worm 最贵，**精英额外昂贵**（Blazing/Overloading/Glacial 为 6 倍，
Malachite/Celestine 高达 36 倍）。精英两级：Tier 1 = 4× HP / 2× DMG（第 1 关起）、
Tier 2 = 18× HP / 6× DMG（第 5 关后），且**相对当前等级乘算** `[实取]`。

**失败代价**
死亡结束本局：金币、道具、本段进度全部作废，回到选 Survivor 的界面重新出发。
跨局保留的是已解锁的道具、Survivor、图鉴条目与成就 —— 与同类一致，**解锁永久、属性不永久**。
另有一条结构性的"时间成本"：因为难度系数含 `timeInMinutes`，
**死亡时的存活时间本身就是失败程度的度量**（结算里显示存活时间与击杀数）`[实取]`。

**紧张从哪来**
① **自己上涨的计时器**：难度系数里 `timeInMinutes` 线性进入乘法，同时每完成一个环境
`stageFactor` 再乘 1.15，于是"多留一分钟刷箱子"永远和"怪变强"直接对冲；正文强调这个增长是指数的 ——
`This increase is exponential, which means that as more Loops are completed, the game becomes
exponentially harder.` ② 传送器事件：`A transparent red dome appears, roughly 120 meters in diameter`
且会 `locks all interactables outside its radius` 直到充满。
③ 资源通胀：交互物价格随难度上涨 `[实取]`。

**核心取舍**
**"再刷一轮"与"现在按传送器"之间选**，且两侧都可量化：难度条按 `coeff` 推进，
每过一个环境整体 ×1.15，所以多留几分钟开箱等于把之后的敌人等级与所有交互物价格一并推高。
第二个高频取舍在同一环境内部：圈定后 `outside its radius` 的交互物都会被锁住，
所以玩家必须在开传送器前决定先吃掉地图的哪一半。第三个是可主动加码的赌博：
Shrine of the Mountain 让该次事件多 100% credits 的敌人，换多 100% 道具掉落 `[实取]`。

**独有机制**
**难度系数这个把时间、人数与关卡数乘在一起的全局标量**，它同时驱动三件本不相关的事：
`coeff = (playerFactor + timeInMinutes × timeFactor) × stageFactor`，其中
`stageFactor = 1.15^stagesCompleted` 使难度随圈数**指数**增长而非线性。
因此"时间"在这款游戏里不是计分板，而是会被玩家主动消费和压榨的资源。
另一条独有设计是 **Lunar 道具的"强效果 + 硬代价"交换率**：两侧写在同一条目上，
玩家每次拾取都要同时接受两侧 `[实取]`。

**被称赞**
本轮从正文里能确认的"被明确称赞"是**玩家反馈被采纳的记录**：团队把精英血量下调
（470%→400%、2350%→1800%）并给出理由 ——
`We've had a lot of feedback that elite health has always felt a bit bloated - and that subsequently,
it makes the Old Guillotine feel required. Our intent is to make characters less reliant on the Old Guillotine.`
玩家与媒体评价类原文本轮**未取得（没找到）** `[实取]`。

**被批评**
本轮从正文里能确认的批评只有**开发者自陈的失衡与修补记录**：
① 精英血量长期偏厚，为此两次下调（见上）。
② 传送器难找 —— 更新记录写道 `A lot of players are having issues finding the Teleporter.
Players are starting to notice the passive particles indicating the teleporter is around.`
③ Drizzle 的回血加成曾因 bug 作用于所有难度，官方自陈
`This was being accidentally applied to ALL difficulties since launch. Oops.`
玩家与媒体批评原文本轮**未取得（没找到）** `[实取]`。

**对 Bronana 的三条**

1. **把难度做成一个显式的全局标量并让它同时驱动三件事** —— 同一根系数决定敌人等级、
   刷怪预算与箱子价格（`baseCost × coeff^1.25`）。→ **战斗**：
   这样"拖延"的代价能被玩家看见并计算，难度阶梯也就有了统一刻度。
   ⚠ 但本作是**封闭单局**（20 波封顶），所以不必照抄"时间进入系数"那一项，
   可抄的是"**一根系数驱动多件事**"这个形状。
2. **给同名道具设计分型叠加而不是统一线性** —— 线性 / 双曲 / 倒数 / 指数四种，
   用双曲封住"100% 无敌"类失衡（Tougher Times 十层也只到 60%），用指数换取高潮。
   → **养成**：一套词条里能同时容纳稳健件与爆发件。
3. **把"加码"做成明码标价的交互物而不是隐藏机制** —— Shrine of the Mountain
   让该次事件多 100% 敌人、换多 100% 掉落。→ **经营**：
   把风险回报摆到台面上让玩家自己签，比藏在掉落表里更有张力。

### 18. 深岩银河 / Deep Rock Galactic

**定位**
3D 第一人称合作射击（官方商店描述为 `co-op FPS`）+ 程序化洞穴挖掘，1–4 人 PvE。
开发 Ghost Ship Games，发行 Coffee Stain Publishing（商店页 legal_notice：
`©2020 Ghost Ship Games ApS. Developed by Ghost Ship Games. Published by Coffee Stain Publishing.`）。
Steam 发售日 2020-05-13（`release_date` = `13 May, 2020`）；平台 `windows:true`（Steam 版），
另有 Xbox One 与 Win10 Store 版本，跨平台只在后两者之间（`NOT the Steam version`）`[实取]`。

**一句话**
一批矮人矿工坐空降舱钻进 100% 可破坏的程序化洞穴，完成主目标（采够矿物 / 清掉无畏 / 护送钻机）后
M.U.L.E. 上的**撤离按钮亮起**，全队必须在几分钟内跑回空降舱；
它不是"一局打到死"，而是"太空站接单 → 降落 → 干完 → 撤离"的任务制循环。

**核心循环**
宿主在太空站的任务终端前先选星区、再选该星区里的具体任务（星区与其中的任务类型每 30 分钟实时轮换）→
走进空降舱降落 → 完成必需的主目标（Mining Expedition 采够莫凯特，数值随洞穴
Length/Complexity 为 200/225/250/325/400；Egg Hunt 取 4/6/8 个异星蛋；Elimination 杀 2 或 3 个无畏）→
顺便完成可选的次要目标换额外信用点与经验 → 主目标达成后 **M.U.L.E. 的撤离按钮解锁** →
按下后呼叫空降舱，多数任务有 5 分钟跑回（On-site Refining 为 3 分钟）→
成功则带回采集到的矿物、经验与信用点；**失败也结算 25%**。回太空站升级装备、接下一单 `[实取]`。

**单局形状**
一"局"= 一次任务。长度不靠计时器而是靠终端上标出的 Length / Complexity 图标，主目标数值随之上升。
任务内部有明确的时间压力段落：主目标达标后呼叫撤离舱，通常剩 5 分钟路程。
Salvage Operation 更碎：修 Mini M.U.L.E. → 修通讯上行并守在绿球里 → 接燃料棒再守一次 →
再撑额外 2 分钟。Deep Dive 把三个任务串成一次连续行动，装备、弹药、HP、已挖的金与 Nitra 全部跨关携带。
多人准备阶段：宿主站进空降舱 15 秒强制开局，全队都进则缩到 5 秒 `[实取]`。

**每分钟在做什么**
手上多数时候不是"打"而是"搬与挖"：挖矿后把矿物送进 M.U.L.E.、铺管线并修漏点（On-site Refining）、
用激光吸 Oil Shale 给钻机加油（Escort Duty）、挖出被埋在墙里的异星蛋或 Aquarq 再扛回平台。
地形全可破坏，所以路径要自己造：钻机手用钻直接钻穿岩层、工程兵架平台枪、侦察兵钩爪上墙、
枪手拉滑索。同时要照看弹药与补给、以及每波虫潮的来向（Tab 开地形扫描仪看地图与标记）`[实取]`。

**一局怎么分段**
分段完全由任务类型决定：Mining Expedition 是脏土墙相隔的线性串洞；Egg Hunt 是中心房由多道脏土墙
通向一个大房；On-site Refining 是一大洞 + 一子洞，找 3 个液莫凯特井 → 从移动精炼站铺管到各泵 →
按按钮开始精炼并在期间清怪与修漏；Salvage Operation 是小起始房 → 巨型洞 → 修 2–3 台 Mini M.U.L.E. →
回收 → 修通讯上行（要待在绿球里，离开即算中断）→ 接燃料棒再守一次 → 再撑 2 分钟；
Point Extraction 是一大洞 + 带三座炮塔的 Minehead 钻塔；Escort Duty 是大起始房 + 数个大洞护送钻机；
Elimination 是找 2–3 个茧打无畏。每个任务还可能带 Warnings（如 Low Oxygen `+20% Hazard Bonus`、
Elite Threat `+30% Hazard Bonus`）与 Anomalies（Double XP、Gold Rush、Low Gravity），
另有随机事件 Cargo Crate、Lost Pack、Machine Event、Data Cell、Core Stone 等 `[实取]`。

**操作方式**
全手动瞄准，没有任何自动攻击或自动索敌。默认键鼠：WASD 移动、鼠标转视角、Space 跳、Shift 冲刺、
E 交互/拾取、左键开火、右键挥镐、滚轮切换装备、1 主武器 / 2 副武器 / 3 工具 / 4 移动工具 /
5 补给工具、Ctrl 激光指示器、R 装弹、F 扔照明弹（长按切头灯）、G 手雷、C 叫 M.U.L.E.、
Tab 或 M 开地形扫描仪、Z 按住语音、V 敬礼。手柄一一对应，Steam 标为 full controller support `[实取]`。

**局内成长**
任务内部**没有**角色等级或属性成长：伤害、血量、弹药容量、武器改装全部来自局外，
Overclock 也要在局外打造后才带进洞。局内能变的只有资源与临时状态：
Deep Dive 里 `All gear, ammo, HP, and mined Gold and Nitra will carry over from one mission to the next`；
在 Abyss Bar 喝的"今日特调"效果也会带进 Deep Dive 的三关；perk 的主动能力在每关之间重置，
所以 Field Medic、Iron Will 这类主动 perk 在一次 Dive 里能用多次；单人时 Bosco 的复活次数同样每关重置。
任务里可以按 5 调出 Resupply Tool 呼叫补给 `[实取]`。

**物品设计**
槽位是固定的四件套：主武器、副武器、工具、移动工具，外加手雷与镐（镐的外观有七个部件可换）。
武器由多层改装构成，而"要装备一个 Overclock，必须先在该武器每一层都至少买一个改装"。
Overclock 分三类并有**明示代价差异**：Clean（绿色三角边框）
`give a boost with no explicit penalty, and are essentially an extra modification tier`；
Balanced（黄色六边边框）`provide a larger boost, usually alongside an equal penalty`；
Unstable（红色方框）`feature the largest boosts, often with heavy penalties.
These are typically the most transformative Overclocks`。全游戏共 160 个可用 Overclock
（Driller 39 / Engineer 39 / Gunner 42 / Scout 40），另有 27 个未使用或被移除；
由 Matrix Core 在 The Forge 用信用点与矿物打造 `[实取]`。

**局外成长**
货币：Credits、XP、六种制作矿物，以及 Phazyonite。解锁偏"能力与新玩法"而不是纯数值 ——
第一次晋升（职业 25 级封顶后做晋升任务并付费）后**账号级**永久解锁三项：
可激活洞穴里随机出现的 Machine Events、新任务 Breach The Core 与 Weekly Core Hunt、以及 The Forge；
对那个职业还额外解锁 Deep Dives、+1 主动 perk 槽、+1 Honor Badge，并让该职业能继续升级。
矿物交易终端（需先完成 Company Benefits: Mineral Trading Network）卖出 50、买入 150 每单位，
且每天有一次 Daily Deal；外观按职业单独购买，也能用 Phazyonite（1 单位 = 200 信用点或 2 矿物）结算 `[实取]`。

**难度机制**
难度是**玩家在任务终端上自选**，而不是逐级解锁：Hazard 1 Low Risk / 2 Challenging / 3 Dangerous /
4 Extreme / 5 Lethal，对应 Hazard Bonus +25% / +50% / +75% / +100% / +133%
（奖励与难度直接挂钩）。同一 Hazard 下还按人数各有一列数值（1/2/3/4 人）：
H5 敌人伤害 2.80/3.00/3.20/3.40，敌攻速 1.50、投射物速度 1.70、移速 1.15，
被救起时的血量倍率从 0.60 降到 0.10，最大生命回复从 15% 降到 10%，
敌人数量 0.85/0.85/1.25/1.50。Hazard 5 以上另有可选修正：Aggressive Enemies、More Enemies、
Player Vulnerability、Tough Enemies，各自 1 级与 2 级 `[实取]`。

**敌人与 Boss**
敌人以 Glyphid 虫族为主，另有飞行的 Mactera、定点的 Spitball Infector / Korlok Tyrant-Weed、
以及 Rival 机器人派系；商店页写作 `over 50 different enemy types`。
Boss 基本等于"任务目标"：Elimination 要杀 2–3 个 Dreadnought（另有极低概率作为随机遭遇出现，
wiki 标 `~1.5% spawn chance`）；Industrial Sabotage 要先断电再在三阶段里打掉 Caretaker；
Escort Duty 最后打 Ommoran Heartstone 四阶段萃取（第一阶段固定是敌人潮，第三阶段又是虫潮，
第二与第四阶段从 Flying Rocks / Ommoran Beamers / Ommoran Crystal Traps 里随机且两次不重复），
钻机在核心脱出前被打掉则任务直接失败。精英（Elite）是普通怪的强化版，Elite Threat 警告让其更常见。
另有 BET-C、Glyphid Crassus Detonator、Golden Loot Bug、Huuli Hoarder、Nemesis 等随机遭遇，
各自标注 5% / 3% / 15% / 15% / 3% 的出现率 `[实取]`。

**失败代价**
被击倒本身不等失败，但"全员被击倒且无复活来源"会让任务自动失败；"某个主目标的必需环节失败"
也直接判负（例如 Drilldozer 被摧毁）。失败并非颗粒无收：
`A failed mission still has some reward, consisting of 25% of credits, experience, and mined minerals.`
成功条件：主目标全部完成 **且** 至少一名玩家被任务结束时的空降舱带走。
职业等级到 25 封顶后不再获得经验，晋升会把等级重置回 1，但
`Previously unlocked items and upgrades are not reset` `[实取]`。

**紧张从哪来**
① 虫潮节奏：Hazard 越高，swarm 之间与普通波之间的间隔越短、每波难度点数越高、
敌池与同波多样性越大。Point Extraction 还有一条随时间恶化的规则 ——
`The longer the players stay in the mission, the larger the size of enemy groups that spawn.`
② **撤离倒计时**：主目标一达成按钮亮起，按下之后只能跑，而 On-site Refining 在按下后
`enemy pressure significantly increases until the mission ends`。
此外 On-site Refining 会随机出现泄漏点要修、Salvage Operation 离开绿球会让进度下降甚至当场失败 `[实取]`。

**核心取舍**
**"这一趟挖到哪一步才撤"**：撤离按钮一按，洞穴压力立刻上升、倒计时开始，
所以玩家必须在"再采一轮矿 / 再打一个可选事件"与"现在就走、别把这一单丢在这"之间选，
而这个按钮是**玩家自己按的**，不是系统到点强制结束。第二组取舍原本是四人分工与路线
（谁挖、谁守、从哪个洞走），但它在单人时被数值与装备补偿掉了 —— 难度表下明确写着
`There is only a small increase of enemy spawns between Solo and 2 Player to compensate for the loss of Bosco.`，
且单人可以用 Bosco 的复活次数替代队友救人 `[实取]`。

**独有机制**
最独有的是**"100% 可破坏地形 + 每个职业一件地形工具"这套组合**：商店页写
`And with 100% destructible environments, you can shape the terrain as you see fit. Dig tunnels,
collapse stalagmites and close off choke points to make your job easier.`
而同一道岩壁对四个职业是四种不同解法 —— 钻机手钻穿、工程兵架平台、侦察兵钩爪、枪手滑索，
因此"路"是队员当场造出来的而不是地图给的。
第二个独有物是太空站里那块**共享任务表**：终端上的星区与其中的任务类型
`will shuffle every 30 minutes in real time` `[实取]`。

`Spelunking co-operative goodness. It's a winner.`（Rock Paper Shotgun）、

### 19. 元气骑士 / Soul Knight

**定位**
俯视角 2D 房间制动作 roguelite（地牢推进 + 大厅式局外成长），单人可玩，
也可 2–4 人局域网或远程联机（P2P，房主作为网络中枢）。开发与发行均为 ChillyRoom（凉屋游戏）。
平台：官网只给出 Google Play 与 App Store 两个入口。发布日期**未取得（没找到）**
（官网新闻列表最早条目为 2023-09-01，不足以推断发售日）。Steam 以 `Soul Knight` 搜索未命中本作，
故 PC 平台亦未取得 `[实取]`。

**一句话**
先在一个能走路、能买东西、能捡武器的"骑士之家"里把这一趟的装备备好
（**大厅里拿到的武器可以直接带进地牢**），再钻进 4 大关 × 5 小关的房间制地牢：
每小关是初始房 → 2 个必经小怪房 → 传送门房，一触发房间门就关上、清空才重开，
打掉每大关第 5 小关的首领才出现传送门。

**核心循环**
在大厅备战（选角色 → 用扭蛋机/门口棕色宝箱/鱼缸/书籍拿武器 → 买饮料、领天赋、种花 → 进地牢门）→
进入 1-1 初始房（1-1 不会出现任何 NPC 与可互动实体）→ 依次清掉基础小怪房
（碰到房间入口内侧即触发，所有通道门关闭，清空后重开）→ 顺路进宝箱房拿武器/宝箱、
特殊房拿额外加成 → 到传送门房进下一小关 → 每大关第 5 小关进首领房，击败首领后门重开、
出现传送门并给一个金色宝箱 → 打完 3-5 后可走蓝色传送门到 3-6 取魔法石通关，
或与超界者对话付 100 金币（金币不足则付 1 点生命上限）开紫色传送门进第四大关 →
到 4-6 取魔法石结算，通关证书上多两颗星 `[实取]`。

**单局形状**
结构是固定的：`关卡模式共4大关，每大关5小关，通常每大关最后一个房间为首领房间，
需要击败首领才能开启传送门。玩家至少连续通过三个大关后才能通关。`
击败 3-5 首领后有两个选择：直接走蓝色传送门通关，或花 100 金币进第四大关
（该花费不受商店半价天赋与加价因子影响）。死亡不是唯一终点：单人模式可以看广告或消耗宝石复活；
联机里全员倒地且无额外复活手段就立刻结算。**局内获得的武器不保存到下次游戏** `[实取]`。

**每分钟在做什么**
主循环是"点按攻击键输出 + 走位"，因为**远程武器是辅助自动瞄准的**：
`瞄准范围：距离角色13格内所有不被障碍物阻挡的敌人（不包括训练桩）；
角色通常会瞄准其中最近的一个，其脚底会有红圈显示。`
玩家实际要照看四项显式数值 —— 生命上限（1~11）、护甲上限（1~8）、能量上限（1~320）、
暴击率（0~15）；护甲先扣，`护甲会以每秒1点的频率自动回复，角色受到伤害后回复暂停，
需要冷却4秒才能重新开始回复`，冷却期间再受伤会把冷却清零；大部分武器每次攻击消耗能量。
此外还要管切枪（最多两把）、省蓝、以及武器的攻击偏移 `[实取]`。

**一局怎么分段**
每小关的房间排在"以初始房间为中心的 5×5 网格"上，只能落在 25 个格位。
第 1~4 小关：初始房与传送门房之间由 2 个必经的基础小怪房连接；宝箱房、特殊房与额外小怪房
随机挂在基础小怪房旁边且必须至少连一个基础小怪房，而
`每个基础小怪房只会与最多1个额外小怪房相连`；初始房与传送门房都只与一个基础小怪房相连。
第 5 小关把传送门房换成首领房，初始房与首领房之间由 3 个基础小怪房连接（第四大关 4-3 只有 2 个）。
另有房间事件：隐藏房/地下室（每小关至多一次）、精英小怪房（红色通道门）、牢笼房，
以及只在冰原/遗迹第 5 小关概率出现的隐藏传送门房 `[实取]`。

**操作方式**
完整的键位表**未取得**（官方 wiki 未提供按键表）。能确证、也是这套操作最核心的事实是自动瞄准：
13 格内不被障碍物阻挡的敌人里通常锁定最近的一个并在其脚底显示红圈，
因此远程武器基本不需要玩家手动瞄准，操作重心落在走位、切枪与能量管理。
几条与操作直接相关的事实：部分武器有多形态，用"切换形态按钮"在形态间切换；
部分武器可以被食用以获得永久的增益或减益，点特殊攻击键食用后武器消失；
当携带的武器与附近地面上的武器可合成时会出现"合成指引"图标，靠近可点融合按钮合成 `[实取]`。

**局内成长**
走房间产出、天赋与商人三条线。小怪房清空后可开白色宝箱，里面是 2 金币 + 2 能量球
（墓穴场景的棺材给 5 金币 + 5 能量球）或武器/小药水；
`房间中可能出现一轮或多轮小怪，一轮小怪全部被击败后，新的一轮才会出现。
随着轮数增加，小怪数量会逐渐减少。` 宝箱房每关通常 1 个（溶洞/沼泽/墓穴偶尔 2 个）；
特殊房"玩家获得额外加成或奖励效果"，可能刷出雕像、工匠、教官、导师、侍者、饮水机、
坐骑商人、金矿/能量矿、许愿池、5 个药丸、重铸/起源/融合熔炉等。
**武器槽有限（两把）**，要换枪就得丢在地上 —— 垃圾桶就是用来丢弃武器的 `[实取]`。

**物品设计**
武器池截至 8.5.0 版本共 520 项（地窖统计）。品质七档：白→绿→蓝→紫→橙→红→品红，
但官方 wiki 明写 `但其仅供参考，与强度并无直接关系`；品红即神话武器，代码品质 6，
自 5.0.0 起取代红武的最高地位。面板只显示攻击力、能量消耗、暴击率、攻击偏移四项，
攻速/蓄力速度/子弹数量/附加效果都不显示。负代价很具体：多数武器消耗能量，少数改用别的资源 ——
撒币枪消耗金币、死神之息消耗生命值、守灵人短斧消耗护甲；攻击偏移是
`射出的子弹偏移弹道基准线的最大角度`。武器还可合成、升级、进化、装配件，部分可食用换永久增益 `[实取]`。

**局外成长**
货币是宝石（Gems）、材料与蓝图/兑换券。解锁以"能力与新内容"为主：已解锁的普通角色
可用宝石逐星升级 —— 1 星生命上限 +1（500 宝石）、2 星护甲上限 +1（1000）、
3 星能量上限 +20（1500）、4 星技能冷却减少（2000，多段技能只减 1 秒）、
5 星技能获得加强效果（2500）、6 星获得被动天赋（5000）、7 星升级初始武器（8000）。
角色解锁方式被列为"免费、付费、宝石、材料、成就"五类。设施也要材料，例如魔法井需
3000 宝石 + 5 蓝魔法碎片 + 5 紫魔法碎片 + 15 铁矿 + 15 木材；花园在做 3 次关卡模式后解锁 `[实取]`。

**难度机制**
难度主体是**炸天模式**，官方 wiki 明说它
`本质上是相比于普通更高的一种游戏难度，而不是一个游戏模式`。它在角色通过 4-5 后解锁，
与炸天小姐姐 NPC 对话开启，效果逐条列明：角色防御 -1 而机甲防御 +1；
小怪房总怪物点数 +100%、密度 +50%；小怪攻击频率 +100%；小怪以精英形态出现的概率增加，
且**首领必定为精英形态**；试炼之地的首领血量 +20%。
第二层是挑战因子，单人要在任务栏接受/更换并花宝石，而联机建房时
`可无限刷新挑战因子，也无需花费宝石`。另外地图生成本身带难度分层：
精英小怪房的通道门是红色，房内所有小怪都是精英形态，清空后额外产出绿色宝箱与随机宝箱 `[实取]`。

**敌人与 Boss**
规则很硬：`房间生成之时内部的所有小怪就均已就位，但在玩家触发该房间前它们不会行动、
且均处于免疫伤害状态或不可选中状态、也无法被附加冰冻和感电效果`；
玩家碰到房间入口内侧即触发，所有连接通道的门关闭阻止离开，小怪立刻解除无敌。
首领房只出现在每大关第 5 小关并取代传送门房，进门后门升起阻止离开，
`只有在击败首领后，房间门才会重新开启，同时传送门出现，并奖励一个金色宝箱，
内含一件武器，有概率为该首领对应的首领武器`。精英小怪房是小地图上带黄色感叹号标示的变种 `[实取]`。

**失败代价**
单人：生命值归零即死，但有"观看广告"或消耗宝石复活的机会。联机：生命归零立刻进入倒地状态，
存活成员交互 4.5 秒可救起，被救者 `生命值会恢复至1点，护甲会回满，但能量不会回复`；
救人过程中救人者受伤或远离会打断。进入下一关时倒地成员会自动以 1 点生命复活。
`当房间内的所有成员全部倒地，且无额外复活方式时，将立即进入结算，
没有像单人模式的观看广告/消耗宝石复活的机会`。局内获得的武器不会保存到下次游戏，
只在地窖里记录获得次数 `[实取]`。

**紧张从哪来**
① **门会关上**：玩家一触发房间，所有连接通道的门立刻关闭阻止离开，必须清空全部小怪才重开，
因此"先探路再选房"的余地很小，**逃跑不是选项** —— 而触发还可能失灵：
`当角色移速过快或处于不可选中状态时，房间可能会因没有检测到玩家因而没有被触发`。
② **资源不自动回满**：大部分武器每次攻击消耗能量（上限 1~320 视角色而定），
护甲虽每秒回 1 点但受伤后要停 4 秒、期间再受伤清零。
联机时还随人数上调强度：`当联机人数为2/3/4时，小怪血量增加25%/75%/125%，
首领血量增加50%/100%/150%，怪物点数增加100%/200%/300%` `[实取]`。

**核心取舍**
**"这一小关要不要绕那间房"**。房间不是线性串联的：初始房与传送门房之间那 2 个基础小怪房是必经的，
但宝箱房、特殊房与额外小怪房都挂在旁边，而且
`每个基础小怪房只会与最多1个额外小怪房相连`，所以每一小关都在
"多打一房换武器/天赋/加成"与"少打一房保住护甲和蓝量"之间选。
第二个具体取舍在打完 3-5 之后：走蓝色传送门直接通关，
还是付 100 金币（金币不足时付 1 点生命上限）开紫色传送门去打第四大关，
用风险换通关证书上的两颗星 `[实取]`。

**独有机制**
**把备战做成一个可以走动的房间集合，并且在这里拿到的东西能直接带进地牢。**
官方 wiki 定义：`大厅是玩家选择角色时的默认场景，是绝大部分角色的聚集地，
玩家在选择角色后可与其他NPC/家具进行互动`；家具有永久提升基础属性的四件
（猫粮升宠物攻与生命、盆栽升移速、书籍升暴击率、保险箱升初始金币）与一批功能家具
（饮料自动贩卖机、任务栏、扭蛋机、棕色宝箱、元气手册、邮箱、展板、招财猫、冰箱、电视机、鱼缸、垃圾桶）；
NPC 包括每天刷新并给宝石与一件武器的快递员、开炸天与赛季模式的炸天小姐姐、领悬赏与换挑战因子的警官。
武器页明确写了这条闭环：`在骑士之家进行备战时，玩家可以通过多种途径获得武器，带入地牢。` `[实取]`

**被称赞**
**未取得（没找到）**。抓到的页面里没有对游戏整体的正面评价原文；能引到的只有开发者自述，
如 `角色没有明显的强弱（如果有，强的将会被削弱哦。。体验一把拳头爸爸削英雄的感觉也是倍爽呢）`，
不构成对游戏的评价 `[实取]`。

**被批评**
① **联机质量**：联机模式页写 `自从远程联机诞生以来，玩家们在该模式中发现了数以万计的bug`，
并说曾在联机中开放的三国赛季模式"存在着一系列问题导致风评极差"，
列举包括过多导致无法正常交互、进度卡死的 bug，以及刷关后玩家无法再次联机。
② **英雄角色设计**：官方最终整套废除该设定 —— 当时推出的英雄角色
`普遍存在技能整体强度过于低下的问题`，再加之充能机制的问题 `[实取]`。

**对 Bronana 的三条**

1. **大厅要有"带得进去"的东西，否则它只是菜单** —— 在骑士之家通过扭蛋机/宝箱/鱼缸拿到的武器
   可以直接带进地牢。→ **经营 / 养成**：本作大厅与枢纽已能走，但"在这里拿到的东西进这一局"
   这条边要显式做出来（`trade.ts` 的 `starter*` 是第一步）。
2. **房间连接用硬规则而不是纯随机** —— 必经房 2 个、额外房每个基础房最多挂 1 个、
   首领房取代传送门房。→ **战斗**：本作 `dungeon.ts` 的"死路留给特殊房"是同一类硬规则，
   可再补"额外房挂载上限"这类约束，让每层的房间数可预期。
3. **资源上限（能量/护甲）要按"受击后暂停回复"而不是"自动回满"** ——
   护甲每秒回 1 但受伤后停 4 秒、期间再受伤清零。→ **战斗**：
   这条让"什么时候挨打"变成可计算的成本，比纯血条更能制造小决定。

> 本节只写"本作与这些参考的关系"，**不判定好坏**。

| 本作的机制 | 最近的参考 | 相同的地方 | 不同的地方 |
| --- | --- | --- | --- |
| 波次竞技场（20 波封顶） | Brotato | 有限段数、每波后商店、6 个武器槽 | Brotato 的武器槽是**变量**（1/12/0/24 把）；本作固定 6 |
| 自动攻击 + 手动模式 | VS / 元气骑士 | 自动瞄准、靠走位 | 本作**额外**给了 `manual`（自瞄 + 按键放技能），两家都没有这一层 |
| 随机地牢 + 自己选房间 | 以撒 / 挺地牢 / Hades | 房间网格、走进门换房、死路放特殊房 | **Hades 的"门上预告奖励"本作还没有** |
| 波间商店 + 词条 | Brotato / Last Epoch | 每件带词条、按品级滚 1~3 条 | **Last Epoch 是 2 前缀 + 2 后缀独立槽；本作是家族并集**（R39 写明理由） |
| 武器合成 T1–T5 | Brotato | 同名同档两把合一 | Brotato 是 4 档；本作 5 档（T5 神话 · 红） |
| 局内营地（3 设施位 / 相邻组合） | Loop Hero / Two Point / RimWorld | 瓶颈 = 玩法、相邻才生效 | **本作的营地是"制造车间"**（产物是装备，不是战斗修饰）—— 三家里没有先例 |
| 跨局据点（买功能不买数值） | DD / Loop Hero / Cult of the Lamb | 建筑给"能做什么" | **本作据点没有"会衰减、必须定期照顾"的那一层**（咩咩有） |
| 天赋树（产物只是开局条件） | Dead Cells / Hades | 局外成长不进模拟层 | 本作是**每角色一棵**；Hades 是全角色共用一棵镜 |
| 图纸工坊（解锁装备与道具） | Dead Cells 的 Collector / Last Epoch 的锻造 | 用局内资源换永久解锁 | **Last Epoch 有"改良已有装备"的 4 条路径；本作只有合成时的 `merge`**（R39 记为缺口） |
| 难度阶梯 10 级（逐级解锁） | Brotato 的 Danger / StS 的 Ascension | 打赢解锁下一级 | **本作难度只改敌人、不给额外产出**；BSC 与 Heat 都给补偿 |
| 每日 / 周挑战（共享种子） | 无直接对应 | — | **这一层在本档案里找不到同类**（最接近的是 RoR2 与 StS 的种子） |
| 三柱闭环（打 → 造 → 再打） | Dave the Diver / Cult of the Lamb / Moonlighter | 两循环互供 | **三家都是两个模块；本作是三条平级轴**（外部无先例） |

**最值得动手的三条**（按"外部有现成做法 + 本作已缺 + 代价低"排序）：

1. **门上预告下一间的奖励**（Hades）—— 本作已有"自己选房间"，缺的只是"先看见再选"。
2. **高难度给额外产出**（Dead Cells 的 BSC：细胞 ×2/×3、物品等级 +1/+3）——
   本作难度阶梯只改敌人，这一半是空的。
3. **改良已有装备的路径**（Last Epoch 的 4 种符文 + Forging Potential 预算）——
   R39 已记为缺口，而外部有完整做法可抄。

**要小心别照抄的三条**：

1. **"公式衰减"与"负代价"不要同时用**（Isaac 的平方根 vs 本作的结构化 `cost`）——
   本作 `data_items.ts` 已经选了后者，同时用就是双重惩罚。
2. **独立前后缀槽不是行业标准**（Last Epoch / PoE 是 2+2，本作是有意的并集）——
   引外部时不要把 2+2 说成"标准"。
3. **第二血条（压力）/ 氧气 / 负重 / 还款倒计时**都是"换一个游戏模型"的大改，
   而用户已明确说过"氧气 / 负重 + 撤离 + 战利品是潜水员戴夫的，不是我的"（E29）——
   要动必须先问，**不能因为"外部都这么做"就加**。
