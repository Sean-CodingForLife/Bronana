# 地基体检账本

> **分工**：地图 [`foundation-map.md`](foundation-map.md) 是**生成的**（枚举 · 归属 · 谁守它，只保证"没漏"）；
> 本文件是**人写的判断**（哪里不合理 · 哪里该补 · 哪里刻意不做）。
> **判据：本文件里每一条缺口，要么指向一道门 / 一个脚本 / 一张声明表，要么写明"刻意不做"的理由。**
> 只写"应该改进"的条目等于装饰 —— 装饰会漂，漂了没人知道。

## 一、为什么要做这次体检

用户的判断（原话大意）：**"你是 agent，总会丢上下文、注意力涣散，于是出现遗漏与偷懒；
正确做法是用文档 + 完整无遗漏的自研体系去保证自动化、工程化、模块化、系统化的开发与运行。"**

⇒ 所以这次体检的产出**不是一份散文报告**，而是三样**结构**：
① 一张**算出来的**地图（`docs/foundation-map.md`，门校验"盘上副本 == 现算"）；
② 这张缺口账本（每条都要落到判据或"刻意不做"）；
③ 把"清单完整性"本身变成**门**。

## 三、这一轮**算出来**的发现（不是凭印象）

### 1. `tools/` 里 **16 个工具没有任何引用**

`apply-comp.cjs` · `batch-close.cjs` · `batch-num.cjs` · `canvas-numbers.cjs` · `decal-decide.cjs` ·
`decal-hoist.cjs` · `esm-ify.cjs` · `esm-tests.cjs` · `finalize-comp.cjs` · `fix-comp.cjs` ·
`fix-types.cjs` · `make-migration-fixture.mjs` · `migrate-types.cjs` · `rename-doudou.cjs` ·
`rewrite-items.py` · `tmp-readme-rows.mjs`

判断：绝大多数是历次大重构留下的**一次性脚本**（`fix-*` / `esm-*` / `migrate-*` / `rename-*` / `batch-*`），
其中两条尤其说明问题：

- **`rewrite-items.py`** —— 一个"零运行时依赖、纯 Node"的仓库里躺着一个 Python 文件；
- **`tmp-readme-rows.mjs`** —— 家法写着"临时脚本放 `tools/tmp-*.mjs`，**验完立刻删**"，
  它没被删；更要紧的是**它被 `.gitignore` 忽略** ⇒ **任何门都不可能发现它**（git 不认识的文件，
  门也不会去读）。这正是"靠人记住的规范都会漂"的活证据。

**处置（本批）**：给这 16 个逐一写了**状态与理由**（`oneoff` 15 个 · `keep` 1 个 ——
`make-migration-fixture.mjs` 是迁移夹具的**生成器**，`test/migration.mjs` 用的是它的产物），
并把这条变成判据（见 §四 P0）；`tmp-readme-rows.mjs` **按它自己的文件头删掉了**。
⇒ 顺带发现我第一版的"可达性"判据**算漏了一种**：`foundation:map` 由门 `doc-num` **间接调用**，
不认这一种就会把在役命令冤枉成死命令 —— 已补上（**判据算不全 = 噪声**）。

### 2. **14 条命令谁都跑不到**

`test:for` · `desktop:gpu` · `desktop:nosandbox` · `verify:quick` · `typecheck:report` ·
`gen:curves` · `text:census` · `ui-preview` · `dev:edit` · `rename:inventory` · `hooks:install` ·
`hooks:status` · `hooks:remove` · `art-manifest`

判断：其中一部分**是合理的手工档**（`hooks:*` 的钩子刻意不装 · `desktop:gpu`/`desktop:nosandbox` 是机器层 · `verify:quick` 的实际用法是 `pnpm verify --quick`），
但**没有任何地方把"这是手工档"写下来** —— 于是"手工档"与"死命令"在机器眼里**无法区分**。
这就是缺一张**命令状态声明表**。

### 3. 文档里的家族数字**漂了**（当场实测）

`docs/requirements.md:1661` 写「`Registry.family` **154** 处 + `SelfCheck.register` **63** 处」；
实测（`Select-String src/*.ts`）是 **156 / 66**。门 `doc-num` 管不到这一处 ——
因为它的判据是**精确锚点**，而这句话不在锚点里。
⇒ 结论：**"锚点之外的手写数字"是一片没有门的荒地**（地图现在把它照出来了）。

### 4. 引擎侧唯一的"文档说它存在、源码里没有"

`docs/workspace-spec.md` 写着"插件与原生模块**走同一套加载器**"，清单类型里也已声明 `plugins.enabled`；
但仓库里**没有加载器**（`plugin` 在 `src/` 的 3 处命中都在清单字段声明里）。
⇒ 这是**引擎这一类最该补的一件**：按清单的**显式顺序**跑三阶段（注册表/自检 → 数据表 → 系统），
判据**零发明** —— 直接拿 `docs/requirements.md:1665` 已经写好的那句：
「**被禁用模块不得被任何已启用模块依赖**」做进 `Module.audit()`。

## 五、外部对照（联网 + skill 联合审查）

三路调研，第一路（**引擎架构**）已回，后两路（工具链/CI · 文档与 AI 协作）进行中。

### 5.1 引擎架构对照（已回）

**① 该补的三件（都指向判据）**
1. **加载期契约**（见 §三.4）—— 抄 Bevy 的要点不是 trait，而是"**注册是有顺序的阶段**"；
   禁止用 import 顺序当初次顺序（`workspace-spec.md` 自己写了要按依赖拓扑排序）。
2. **`Workspace.parse` 再紧一格**：`modules.enabled[]` / `plugins.enabled[]` 里写了**不存在的 id** 今天被静默忽略
   —— 加两条判据（这比 Cargo 的 `workspace.metadata`"**静默忽略、连警告都没有**"更严，值得保持领先）。
3. **工作区加一份 lock**（抄 Unity `packages-lock.json` / `Cargo.lock`）：判据只有一条
   「清单变了 ⇒ lock 必须跟着变」；否则"同一份清单在两台机器上解析出不同插件版本"会破坏可复现（门 `repro` 已经把可复现当资产）。

**② 明确不偷的（避免过度设计，这一节与"该补"同等重要）**
完整资源管线 · 跨平台逐位确定性（定点数/自研 libm）· ECS · 引擎级 UI 框架（替掉 DOM）·
事件音频中间件 · 两套发现机制 · `Registry.uses` 再扩一层 · 事件总线独立成模块。
每条都有理由，最典型的判据：**"零素材"是工作区的项目规范，不是引擎的能力边界** ——
所以正确动作是把这条规则挪进工作区规范，引擎侧只留"句柄 + 引用计数"。

**③ 已经做对、别人反而没有的（最该保住的一节）**
扩展点**两张表 + 一处自检**（且自注册在拥有数据的模块里）· 门自身的**元门**（`ciDrift`：门清单 ↔ CI 步骤对账）·
**两道指纹门**（`fingerprint` 跨版本 / `repro` 跨进程，且"单跑一遍的指纹是自证的"这个论证写死了）·
**带真实 CTM 的 Canvas2D 桩**（抓"先建路径后 translate"这类只有浏览器才暴露的错）·
美术宪法**运行期拦截**（而不是文档条款）· `engine-first.md` 的**引擎能力包**（抽象 + 与内容无关的示例 + 测试 + 注册总账）·
**SOLID 逐条量成数且基线只许变小** · 以及三条纪律本身
（**数量一律从清单算** / **一条判据只能有一个出处** / **会改行为的必须显式选择**）。

> ⚠ 外部对照里**未取证**的两条已在调研报告中标出（Godot `--headless` 的确切开关名；
> Unity asmdef"循环引用是编译错误"来自二手来源）—— **用之前必须复核**，不许当结论引用。

## 六、刻意不做（这一层同样重要）

- **不引入** ESLint / Prettier / 打包器 / 任何运行时依赖（零依赖是设计约束，不是现状）。
- **不做覆盖率门** —— "覆盖率涨跌多少算红"没有客观判据，做成门只会逼人写无意义的测试
  （这条已经写在 `tools/verify.mjs` 末尾那段"刻意没放进 CI 的东西"里）。
- **不装 git hook** —— 钩子是**机器层**的，装不上/被绕过会**静默失效**；判据留在 `pnpm verify`。
- **不给"没人守的家族"加自检** —— 纯声明表加自检是同义反复（保持黄）。
